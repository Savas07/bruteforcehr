# Component inventory

Status: M0 synthesis, 2026-10-22. One list merged from the "Components needed" section of every research doc (14 areas), deduplicated and renamed where two docs used one name for different things. Usage rules and tokens are in [system.md](system.md).

**Columns**

- **Platforms:** iOS · D (desktop: macOS + Windows) · W (website).
- **Desktop primitive:** Radix (`@radix-ui/react-*`) · cmdk · dnd-kit · TanStack Table + Virtual · plain HTML. "—" means none.
- **iOS primitive:**
  - Native stack, native tabs.
  - Form sheet with detents (medium / large).
  - Context menu (UIMenu), swipe actions.
  - SF Symbols (names in `code`).
  - Haptics (meaning from `@bfhr/ui-tokens/native` `haptics`).
  - System controls: UISwitch, segmented control, date picker, search bar, action sheet.

  The iOS shell owner picks the library for each; a JS imitation of a native control isn't allowed (BRIEF §5.4).

- **M0:** the core screens that use the component (T Today · JD Job detail · CV CV editor · TB Tracker board · MR Mail review). Blank = later milestone.

**Renames** (two docs used one name for different things):

- Tracker's follow-up / ghosted `SuggestionCard` → **`NudgeCard`**; Apply's AI `SuggestionCard` → **`AiSuggestionCard`**.
- Apply's `TemplatePicker` (email and cover-letter text) → **`TextTemplatePicker`**; CV Studio's → **`CvTemplatePicker`** / **`CvTemplateGallery`**.

**Merged** (same component, one name):

- `InlineNotice`, `InlineErrorBanner` → `InlineAlert`.
- `DestructiveConfirm`, `DisconnectDialog` → `ConfirmDialog`.
- `StickyActionFooter` → `StickyFooterBar`.
- `KeyboardShortcutHint` → `Keycaps`.
- `InsightsEmptyState` → `EmptyState` + `LowSampleNotice`.
- `SwipeActions` config and `RowContextMenu` → the row components + `Menu`.
- `HiddenRowPlaceholder` → a `JobRow` state.
- `SourcesFootnote` → part of `SourcesList`.
- `DetailRail` (job detail, 280 px) → part of the job-detail layout.
- `ImportReviewHeader`, `SelectionSummaryBar`, `ReviewGroupHeader`, `ProposalRow` / `ProposalTableRow` and `EvidencePanel` → parts of the backfill `ImportReview`.
- `ConnectionStatus`, `AccountStatusRow`, `AccountStatusPill` and `AccountHealthBanner` → **`AccountStatus`** (pill / row / banner variants).
- `Toast` (onboarding), `UndoToast`, `UndoSendToast`, `CopiedToast` → **`Toast`** (variants: `undo`, `undoSend`, `info`).
- `SaveStatus` → **`SyncStatus`**; `CsvExportButton` → **`ExportButton`**.
- The `insights` selectors are pure functions in `@bfhr/core`, not UI components.
