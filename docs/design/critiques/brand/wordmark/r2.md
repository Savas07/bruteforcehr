## Design Critique: Wordmark on the website

### Overall Impression

The lockup reads cleanly in both themes and replaces two elements (mark + system-font text) with one drawn unit. At 375 px it leaves room for the nav item, and the teal "HR" ties the header to the active nav pill without competing with it.

### Usability

| Finding                                                                                                                                                                         | Severity | Recommendation                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Header 375 px: lockup 183 × 24 px inside a 199 × 44 px link; the "Support" pill still fits on the same row.                                                                     | —        | Pass.                                                                                                                           |
| The interim header showed the name at `text-title2`; the outlined lockup no longer scales with the browser's minimum-font-size setting (it does scale with page zoom).          | 🟢 Minor | Accept: logotypes are exempt (WCAG 1.4.4/1.4.5); the name is also the page title and the footer copyright line, both live text. |
| Dark theme: the plate's lower edge (`#1B5954`) is 2.18:1 against `surface.base` `#16191F`; the plate still reads as a tile because the B and the upper edge (3.84:1) define it. | 🟢 Minor | Log (same as app icon r1 #7).                                                                                                   |

### Visual Hierarchy

- **What draws the eye first**: the plate in the header, then the page title. Correct: the brand anchors the page without being the loudest element.
- **Reading flow**: plate → "BruteForce" → teal "HR" → nav.
- **Emphasis**: the teal appears in the plate, in "HR" and in the active nav pill; three uses of one hue, no new colour.

### Consistency

| Element                 | Issue                                                                           | Recommendation |
| ----------------------- | ------------------------------------------------------------------------------- | -------------- |
| Header vs footer        | Same component and size in both places; the footer link keeps its 44 px target. | —              |
| Favicon vs header plate | Same plate and gradient; the tab and the header match.                          | —              |

### Accessibility

- **Name, role**: Playwright accessibility snapshot of `banner` → `link "BruteForceHR"` containing `img "BruteForceHR"`; one link per location (header, footer).
- **Keyboard**: second Tab stop (after the skip link) is the header lockup link, 199 × 44 px, 2 px solid focus outline.
- **Contrast**: as in [r1](r1.md); all text parts ≥ 7:1 in both themes.

### What Works Well

- The calm half of the name carries the colour.
- The lockup is generated from the same SVG master as the app icon, so the B in the header and on the Dock are the same drawing.
