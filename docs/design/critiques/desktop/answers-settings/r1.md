## Design Critique: Application answers

### Overall Impression

The grouped list on the left reads like the kit (Work authorization, Availability, Compensation, Links, Questions and answers), each row with its first value and its tags ("EU · EN/DE"), and the editor on the right shows everything one answer needs without tabs: group, label, one text box per language, countries, currency for salary.

### Usability

| Finding                                                                                                 | Severity | Recommendation                                                                                                              |
| ------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------- |
| 1. The editor is taller than 800 px; Save sits below the fold for a three-language answer.              | 🟢 Minor | Logged: Enter in a single-line field saves; the form is a normal scroll.                                                    |
| 2. Countries are typed as codes ("DE, EU"); a picker would be friendlier.                               | 🟢 Minor | Logged: the hint names the format with examples and the error says how to fix it; a picker can come with M6's country list. |
| 3. Empty/loading/error follow the pane conventions (EmptyState with "Add answer", skeleton, PaneError). | —        | Pass.                                                                                                                       |

### Accessibility

- axe: 0 critical · 0 serious · 0 moderate · 0 minor. The list is a labelled `nav` with `aria-current` on the open answer; validation errors are `role="alert"` and move focus to the field; Move up/down explain why they are disabled.

### What Works Well

- Values in other languages are kept when edited here; delete has Undo.
