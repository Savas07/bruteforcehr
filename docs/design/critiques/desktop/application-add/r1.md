# Log an application (desktop) — critique round 1

Stage: refinement (real implementation, browser harness, WebKit ≈ WKWebView). Persona: Deniz, an active job seeker logging an application they sent from a company site, often stressed and short on time, keyboard-first on desktop. Goal: record company + role in seconds, optionally the link, date, channel and CV used, without losing the board context.

## References (Mobbin, web)

Examined 30 candidates over four queries ("create record dialog with company and job title fields", "add job application form in a job tracker…", "create deal modal in a CRM with pipeline stage select…", "create form showing a possible duplicate record warning…"). Kept:

## Design Critique: Log an application

### Overall Impression
A calm, compact modal that reads top-down in the right order (who → what → where it stands → extras). The first capture had the rows collapsing into each other (no row gap) and gave no visible hint of the keyboard path; the error state repeats every message twice.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Rows had no vertical gap: each label sat on the previous input (first capture; Tailwind wasn't scanning the new folder because `.git/info/exclude` listed it) | 🔴 Critical | Fix the scan (exclude line removed by DesktopTracker); keep `gap-y-4` rows |
| Keyboard path (⌘↩ adds from any field) only discoverable through the primary button's tooltip | 🟡 Moderate | Footer-left keycap hint "⌘↩ to add" (Attio pattern); hide it offline where the offline note takes the slot |
| Error summary repeats each field's full message, so 4 errors push Notes below the fold | 🟡 Moderate | Summary lists field names as links that focus the field; the message stays under the field |
| Location next to Link squeezed the URL field to half width; Sent via sat alone on its row | 🟡 Moderate | Link full width; pair Sent via with Location |
| Notes textarea rendered one line high (the shared `h-8` beat `h-auto`) | 🟡 Moderate | Separate control class without a fixed height for the textarea |
| Choosing Saved/Preparing hides "Applied on" and leaves Status alone on its row | 🟢 Minor | Accept: the date only means something from Applied on; the jump is one row |
| WebKit shows the typed date in US order after `fill` in the harness | 🟢 Minor | Native control, follows the engine locale; the app's WKWebView follows macOS. Log only |

### Visual Hierarchy
- **What draws the eye first**: the title, then the focused Company field — correct.
- **Reading flow**: Company/Role → Link → Status/Applied on → Sent via/Location → CV/Version → Notes → footer.
- **Emphasis**: one primary ("Add application"); "Add and open" secondary; Cancel plain. The duplicate note is info-blue, not red.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Field style | Matches CreateCvDialog / snooze date fields (h-8, `line-control` border, footnote labels) | Keep |
| Status labels | Shared vocabulary ("Not selected", "No response") grouped by phase like the board | Keep |
| Discard confirmation | Same AlertDialog shape as "Save your changes before restarting?" | Keep |

### Accessibility
- **Color contrast**: axe found no contrast violations; "needs review" items are the scrim-covered board behind the modal.
- **Targets**: 32 px controls and buttons.
- **Readability**: callout text in fields, footnote labels; the optional hint in tertiary only on the label's suffix.

### What Works Well
- Status preset from where the dialog was opened, Applied by default, today pre-filled in the user's zone.
- The duplicate note says what exists and offers "Open it" without blocking the add.
- Empty state (no CVs) explains where CVs come from instead of showing a dead select.

### Priority Recommendations
1. **Row spacing** — restore the 16 px row gap so the form scans.
2. **Visible keyboard hint** — ⌘↩ in the footer.
3. **Shorter error summary + full-width link + real textarea height.**

## Resolution

| Finding | Resolution |
| --- | --- |
| No row gap | Fixed — DesktopTracker removed the `.git/info/exclude` lines; captures re-taken (row gap 16 px confirmed by computed style) |
| Keyboard hint | Fixed — footer "⌘↩ to add" (`application-add.dialog.keysHint`), hidden while offline |
| Error summary duplication | Fixed — summary lists field names (`SUMMARY_NAMES`) as focus links |
| Link half width / lonely Sent via | Fixed — Link spans both columns; Sent via + Location share a row |
| Textarea height | Fixed — `controlClass` without height for Notes |
| Applied-on row jump | Rejected (logged) — date is meaningless for Saved/Preparing |
| WebKit date order | Rejected (logged) — native control |
