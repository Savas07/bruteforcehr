## Design Critique: Application detail (desktop), round 2

### Overall Impression
The r1 reorder works: on Brightwave at 1280 × 800 the automatic "Moved to Interviewing · Automatic · Mail" row with **Undo** and **View source** sits at y ≈ 510, above the fold, and the upcoming round leads the side column. One next step at a time holds in every state judged. What remained were keyboard details: focus fell to the start of the page after most dialogs, axe flagged every open menu, and the bottom "Application" block said the status and documents a second time in other words.

### TR / DE fit (1280 × 800 and 1920 × 1080)
- **DE** (longest): the header row holds "Stellenanzeige öffnen" + "Auf Hiring manager interview vorbereiten" on one line next to "Seit 2 Tagen in „Vorstellungsgespräch“"; the stage strip labels ("Eingang bestätigt", "Vorstellungsgespräch") fit their columns; "Erinnerungen zur Interviewvorbereitung auf diesem Computer" wraps to two lines beside the switch without pushing it; the reminder line keeps "Ändern" / "Entfernen" on the same row. No truncation, no overflow.
- **TR**: "2 gündür Mülakat aşamasında", "Hazırlanın: Hiring manager interview", "New York saatiyle 10:00–10:45", "Zamanı: Çarşamba, 17:00" all on one line; nothing clipped.

### Visual Hierarchy
- **First:** role title, then the one teal primary (or, with a suggestion due, the Up next card). Unchanged and right.
- **Reading flow:** header → stage strip → Up next / Timeline (left) and Interview rounds → Reminders → Documents → Contacts → Notes → Application (right). After the fix the last block no longer re-states the top of the page.

### Consistency

| Element | Issue | Recommendation |
|---------|-------|----------------|
| Menus | Detail page menus now behave like the board's: same keys, same focus return. | — |
| Dialog focus | Form dialogs, Delete and the inline editor now all return focus where the user was, like the Radix-trigger dialogs elsewhere (Link existing already did). | — |
| Cover letter wording | One wording per page after the summary fix ("No cover letter"). | — |

### What Works Well
- Automatic change with source and Undo is visible without scrolling; after Undo the row reads "Undone".
- The closed state is calm: grey "Not selected", "Closed 16 days ago", no red, no primary.
- German and Turkish fit the 1280 layout without any wrapping hacks.

### Priority Recommendations
1. **Return focus after dialogs** — keyboard users keep their place.
2. **Non-modal menus** — no app-wide `aria-hidden` while a menu is open.
3. **Say status and documents once** — trim the bottom block on the full page.

## Resolution

| Finding | Status |
|---------|--------|
| Focus falls to `<body>` after dialogs | **Fixed** — `fields.tsx` `FormDialog`: remembers the focused element when it opens (all callers mount it open) and returns there in `onCloseAutoFocus`; `Screen.tsx` `DeleteDialog` `returnFocus` → More actions; `Reminders.tsx`: closing the inline editor focuses the line's first button. Re-probed (WebKit): `DIALOG Add round: opened focus=select … after Esc focus=button "Add round"`, `Edit Hiring manager interview` → same button, `Add contact` → "Add contact", `Edit Marcus Reid` → same, `Change CV` → "Change CV", `Change` (reminder) → "Change", `MENU detail More→Delete: dialog focus=button "Cancel" | after Esc focus=button "More actions"`; Save in the reminder editor → `focus after save: Change`. ⌘↩ "Prepare" starts with nothing focused and returns to the page, as before. |
| axe `aria-hidden-focus` with a menu open | **Fixed** — `modal={false}` on `shared/ui/SnoozeMenu.tsx`, `shared/ui/StatusPill.tsx` (`InteractiveStatusPill`) and the page's More menu. Probe: `MENU detail H: … aria-hidden nodes=0 | Tab→ menuitem "Later today" (menu open: 1) | Esc closed=true focus=button "Snooze"`; `MENU detail M: … aria-hidden nodes=0 | … Esc closed=true focus=button "Status: Interviewing, changes status"`; Today `H` likewise. axe with the menu open: `a11y rem-snooze-menu-light-webkit: 0 critical · 0 serious · 0 moderate · 0 minor · 3 needs review`. |
| Status and documents said twice | **Fixed** — `ApplicationSummaryBlock` additive `trackedElsewhere` (default false); `Screen.tsx` passes it. `ad-bottom-{light,dark}` now shows Applied via · Applied · What usually happens next. |
| Duplicate Back to Tracker on empty | **Logged** (Minor). |
| 26 vs 27 days | **Logged** (Minor). |
| "Edit interview round" title from Prepare | **Logged** (Minor). |
| Clipped Role placeholder | **Logged** (Minor). |
| English fixture text in TR/DE | **Logged** (data). |
