## Design Critique: Application kit

### Overall Impression
Top to bottom it follows the round trip: "Did you submit your application to Northstar Maps?" with the three honest answers, one line of instruction, the CV as a real file with Open / Show in Finder / Copy path, the cover letter switch, and the answers grouped as in Settings. The footer keeps "Open company site again" with the host it opens.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| 1. Answers start below the fold at 1280 × 800 because the CV row explains where the file is saved. | 🟢 Minor | Logged: the file row is what the form needs first; answers have 1–9 copy shortcuts shown on their buttons. |
| 2. The research's drag handle and pop-out window aren't built. | 🟢 Minor | Logged: Copy path + Show in Finder cover the upload dialog; a pop-out is a separate window type (follow-up). |
| 3. No answers yet → one sentence and "Application answers" to Settings (empty state verified in unit tests). | — | Pass. |

### Visual Hierarchy
- One primary at a time: "Yes, I applied" while asking, otherwise "Open company site". Copy buttons are secondary and name their row for screen readers ("Copy Notice period").

### Accessibility
- axe: 0 critical · 0 serious · 0 moderate · 0 minor. Copy buttons have `aria-label` with the row label; the toast names what was copied; Y / N answer the prompt; long answers expand with `aria-expanded`.

### What Works Well
- The file is saved only when used, to one predictable folder; the backend opens or reveals only PDFs in it.

## Resolution
