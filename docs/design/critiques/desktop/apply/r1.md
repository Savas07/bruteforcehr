# Apply by email (desktop) — critique round 1

- **Screen / goal / persona / stage:** `EmailApplyPanel` in the Jobs detail column (`/jobs/job-fernweh-frontend?apply=1`; design build turns the Fernweh Reisen posting into an email posting). Goal: send one careful application by email (or, without a sending account, send it from the mail app and record it) with the right CV pinned. Persona: stressed job seeker applying to a German posting from a Turkish/English profile. Stage: first implementation.
- **Captures judged:** `pnpm --filter @bfhr/desktop capture:design apply --states populated --themes light,dark --sizes 1280x800` → `artifacts/screens/desktop/harness/{webkit,chromium}/apply-populated-{light,dark}-1280x800.png` (gitignored).

## Design Critique: Apply by email

### Overall Impression
Calm and familiar: it reads like a mail client's compose form, prefilled in the posting's language, with the source of the address ("From the job posting") and the language choice explained. The biggest gap is that what gets attached is invisible at 1280 × 800 until the user scrolls.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| 1. The CV picker and the attachment chips sit below the fold at 1280 × 800; the footer only says "Review email", so the user commits to Review without seeing which CV goes out. | 🟡 Moderate | Show the attachments in the footer's status line when nothing blocks ("Attaching: Lebenslauf — Deutsch"); the blocker sentence replaces it when something does. |
| 2. Two steps are implied but not stated in the header (no "1 of 2"). | 🟢 Minor | Logged: the primary label ("Review email") already names the next step; Review has an Edit button back. |
| 3. Message textarea uses relaxed leading; blank paragraph lines look like double gaps. | 🟢 Minor | Logged: keeps the plain-text paragraphs readable; revisit with the iOS composer for parity. |
| 4. Native selects for From and CV. | — | Pass: keyboard and screen-reader behaviour for free; options carry provider and CV language + age. |

### Visual Hierarchy
- **What draws the eye first:** the title "Apply to Fernweh Reisen", then the prefilled To. Correct.
- **Reading flow:** From → To (with source) → Subject (with language) → Message → CV → Cover letter → Attachments; the one primary is bottom right.
- **Emphasis:** only the primary is filled; hints are tertiary text.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Fields | Same control classes and label/hint pattern as Add application. | — |
| Toasts | Undo-send uses the shared `undoSend` toast (countdown, Undo, Send now). | — |
| Copy | Status names from the shared dictionary ("Applied"); "Not selected" not involved. | — |

### Accessibility
- **Color contrast:** tokens only (`fg-secondary`/`fg-tertiary` on `surface-base`, accent primary) — tested pairings.
- **Targets:** 32 px controls, 32 px close button.
- **Text readability:** callout 13 px fields, footnote hints; long German subject fits at 1280.

### What Works Well
- Template language follows the posting (German, formal "Sie" to the employer) while the UI stays in the user's language.
- Every automatic choice says why: address source, language source, CV "current version … kept with the application".

### Priority Recommendations
1. **Show what's attached without scrolling** (finding 1).

## Resolution

| # | Finding | Severity | Resolution |
|---|---------|----------|------------|
| 1 | Attachments below the fold | 🟡 | **Fixed**: compose footer says "Attaching: {files}" (`apply.email.panel.attaching`, TR/DE added) unless a blocker sentence takes its place. |
| 2 | No step count | 🟢 | **Logged**. |
| 3 | Relaxed textarea leading | 🟢 | **Logged**. |
