- **Screen / goal / persona / stage:** extra attachments in the email composer (research/apply.md "Attachment picker", Braintrust drop zone): saved PDFs or files from the computer, within the account's limit (`mailSendMaxAttachmentBytes`). Final round for M4 Apply.
- **Captures judged:** `capture:design attachment-picker --states populated,empty,loading,error,offline --themes light,dark --sizes 1280x800,1920x1080 --axe` (40 captures, 20 axe reports). Route `/jobs/job-fernweh-frontend?apply=1&letter=ai&attach=files` ("From your files…" open).

## Design Critique: Attachment picker

### Overall Impression
The dialog says what the files are ("CVs and cover letters you made in BruteForceHR"), groups them (CVs, Cover letters) with date and size, and the primary counts what will be attached ("Attach 2 files"). In the composer the attachments section lists every file with its size and a remove button (not on the CV and letter), and the limit line names the account ("Up to 5 files and 18.9 MB in total with deniz@…").

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| 1. The dialog didn't open when the capture switched from the cover-letter state in the same page (the open flag was read only on mount). | 🟡 Moderate | **Fixed:** `?attach=files` opens it whenever the route asks. |
| 2. A refused file (type, count, size) is explained in one line under the buttons; the user isn't told which files were still added when several are dropped. | 🟢 Minor | Logged: the line names the first refused file; added files appear as chips right above. |

### Accessibility
- axe: 0 critical · 0 serious · 0 moderate · 0 minor. Checkboxes are labelled by the file row; remove buttons name the file; the status line is `role="status"`; the drop zone is an enhancement (both buttons do the same).
