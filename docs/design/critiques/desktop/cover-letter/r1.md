- **Screen / goal / persona / stage:** the composer's cover letter (BRIEF §4.4.2): template, tone, language, AI draft or template without AI, merge fields with "Fields to fill", Save as template. Final round for M4 Apply.
- **Captures judged:** `capture:design cover-letter --states populated,empty,loading,error,offline --themes light,dark --sizes 1280x800,1920x1080 --axe` (40 captures, 20 axe reports). Route `/jobs/job-fernweh-frontend?apply=1&letter=ai`: an AI-drafted German letter with `{hiring_manager}` unresolved and an extra attachment.

## Design Critique: Cover letter

### Overall Impression

The toolbar reads in one line (Template · Tone · Language), the two ways to start ("Draft with AI", "Use template") sit right under it, and the unresolved field is impossible to miss: it stays as `{hiring_manager}` in the text, gets its own input under "Fields to fill", and the footer says in one sentence why Review waits.

### Usability

With the letter on, the editor sat below the fold at 1280 × 800 (From/To/Subject/Message/CV first).                         | 🟡 Moderate | **Fixed for the forced state** (opens scrolled to the letter); in normal use the footer blocker names the field, and "Fields to fill" sits right under the letter. | 4. Tone's label sits 4 px lower than Template's and Language's.                                                                | 🟢 Minor    | Logged (segmented control height).                                                                                                                                                                                                                                         |

### Visual Hierarchy

- Primary remains "Review email"; "Draft with AI" is secondary with the sparkle, "Use template" a text button with a tooltip saying it replaces the letter without AI.

### Accessibility

- axe: 0 critical · 0 serious · 0 moderate · 0 minor in all runs. Every control has a visible label; the tone group is a labelled radio group; "Insert field…" is a labelled select; unresolved inputs carry `aria-invalid`; the blocker line is `role="status"`.

### What Works Well

- Merge fields go through core `fillMergeFields` everywhere (subject, body, letter, PDF, copy), so what is shown is what is sent.
