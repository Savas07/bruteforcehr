# CV Studio — live editor (desktop) — accessibility audit

## Accessibility Audit: CV editor on live data (`/cvs`, `/cvs/$cvId`)
**Standard:** WCAG 2.1 AA | **Date:** 2026-10-23

Method:

1. Automated: `pnpm --filter @bfhr/desktop capture:design cv-editor --axe` (axe-core, `wcag2a/2aa/21a/21aa`) on populated, empty, loading, error, offline × light/dark × WebKit and Chromium, before and after the fixes. Reports: `artifacts/a11y/desktop/cv-editor-*.json`.
2. Real-app captures from CI run 39956605907 (`{macos,windows}/cv-studio/editor-editing-{light,dark}.png`) for WebView2/WKWebView rendering.
3. Contrast: token pairs computed with `@bfhr/ui-tokens` `contrastRatio`.
4. Keyboard and screen reader: the editor's form, jump bar, reorder keys and preview canvas were audited in the earlier round ([cv-editor/accessibility.md](../cv-editor/accessibility.md)) and are unchanged; this round re-checks the header and the preview. No VoiceOver/NVDA session was run; "Announced As" is [INFERENCE] from roles and names.

### Summary
**Issues found:** 2 | **Critical:** 1 (fixed) | **Major:** 1 (fixed) | **Minor:** 0

Before: `cv-editor-populated-dark-*` and `cv-editor-offline-dark-*`: **53 serious** color-contrast each (WebKit and Chromium). After: **0 critical · 0 serious · 0 moderate · 0 minor** in all 20 reports.
