## Design Critique: CV editor (live)

### Overall Impression
The three-pane layout reads well and the form is calm and familiar. The biggest problem was invisible in light mode: the live preview ignored the template's own colours and sizes, so in dark mode the CV page was near-white text on a white sheet.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| In dark mode the preview page is unreadable: CV text renders `#ECEEF2` on the white sheet (axe: 53 × color-contrast, 1.16:1, `cv-editor-populated-dark-*`). Cause: cv-render puts the ink, accent, font-size and line-height variables on `:root`, which matches nothing inside the preview's shadow root, so text inherits the app's colour and size. In light mode the same bug means the preview ignores the chosen accent colour and the template's type sizes, so it doesn't match the exported PDF (trust: "what you see is what you send"). | 🔴 Critical | Map the template's `:root` rules to `:host` when the CSS is adopted into the shadow root. |
| At 1280 × 800 (the 13" target), the toolbar (suggestions, Export, History, Inspector) squeezes the title to "Base CV …" and wraps the save status onto two lines. The CV's name is the one thing the header must say. | 🟡 Moderate | Let the toolbar wrap below the title when the column is narrower than title (≥ 240 px) + toolbar; allow the title two lines. |
| The Windows dark capture shows the sidebar on a white material with faded labels while the content is dark (`windows/cv-studio/editor-editing-dark.png`). Comes from the shell's Mica background on the CI runner, not this screen. | 🟢 Minor | Out of scope here; flagged for the shell/foundation owner. |
| The "Created E2E CV …" toast stays over the form through several real-app captures. | 🟢 Minor | Toast lifetime is the shared `Toast`; no change here. |

### Visual Hierarchy
- **What draws the eye first**: the CV's name, then the open Summary field. Correct.
- **Reading flow**: list → form → preview, left to right; the section jump bar under the header gives a second, faster path.
- **Emphasis**: suggestion badges ("1 suggestion") are the only accent-coloured items in the form, which is right; the preview page is the brightest surface in dark mode, as a document should be.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Save status | Uses the shared `SyncStatus` strings ("Saved · last week", "Saved on this device"). | — |
| Preview page | Same renderer as the export, now with the template's own variables. | — |

### Accessibility
- **Color contrast**: preview text failed in dark mode (above); app chrome passes (see the audit).
- **Targets**: 24–32 px controls, desktop pointer.
- **Text readability**: body 15 px in the form; the preview is a scaled document.

### What Works Well
- First use offers exactly two clear choices (Import a CV / Start from scratch) with the import as the primary card.
- Loading uses layout-shaped skeletons; error says the CVs are safe and offers Try again.
- Offline keeps editing and says "Saved on this device".

### Priority Recommendations
1. **Fix the preview's template variables** — it's unreadable in dark mode and doesn't match the PDF in light mode.
2. **Keep the CV name readable at 1280** — wrap the toolbar instead of truncating the title.

## Resolution

| # | Finding | Severity | Status |
|---|---------|----------|--------|
| 1 | Preview ignores the template's `:root` variables (dark text 1.16:1; accent and sizes missing) | Critical | Fixed: `PreviewPane.tsx` `shadowCss` rewrites `:root{` to `:host{` before adopting the sheet (also fixes the Design tab thumbnails, which share `useCvShadow`). Re-run: `cv-editor-populated-dark-*` axe color-contrast 53 → 0. |
| 2 | Title truncated at 1280 | Moderate | Fixed: the header row is `flex-wrap`; title block `min-w-60 flex-1`, `line-clamp-2`; toolbar `ml-auto`, so it drops under the title on narrow columns and stays beside it at 1920. |
| 3 | Shell sidebar material in Windows dark capture | Minor | Logged (shell). |
| 4 | Toast lingering in captures | Minor | Logged (shared Toast). |
