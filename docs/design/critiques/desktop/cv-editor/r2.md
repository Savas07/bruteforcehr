## Design Critique: CV editor (list · editor · preview · inspector)

### Overall Impression
The screen now tells the user within two seconds that three suggestions wait for them ("3 suggestions" in the toolbar, a badge on each affected role), while the form stays calm: collapsed role cards with title, org · dates and the first line. The preview remains the honest, paginated A4 page.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Suggestions are discoverable at every width: toolbar button opens the Suggestions tab; F8 / Shift+F8 step through them in the form and expand the right card. | — | Keep. |
| Placeholder flow: "Use suggestion" stays disabled with the visible reason until "[X%]" is filled; Mod+Enter then applies it with an Undo toast (keyboard pass confirmed). | — | Keep. |
| In the Suggestions tab, "Show in CV" wraps onto its own line below Use / Keep at 340 px. | 🟢 Minor | Logged: acceptable at this width; revisit if a fourth action is added. |
| Below 1280 the icon list shows the language code only; the role/language difference between variants is in the tooltip and accessible name. | 🟢 Minor | Logged: two CVs fit; revisit when a user has several role variants in one language. |
| The jump nav still clips trailing sections at 1280 (now real buttons, so Tab reaches them). | 🟢 Minor | Logged (carried from r1). |

### Visual Hierarchy
- **What draws the eye first**: the CV title, then the "3 suggestions" button (accent sparkle) — correct for today's job.
- **Reading flow**: title → suggestions → sections; collapsed role cards make Experience scannable in one screen at 1280.
- **Emphasis**: the accent gutter on cards with pending suggestions ties the badge, the inline change and the queue together without colour carrying meaning alone (badge text + gutter).

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Suggestion vocabulary | "Use suggestion · Keep original · Edit", disclaimer and toasts match decisions.md D13 in the form, the queue and TR/DE. | Keep. |
| Pills and badges | Language pill, "Default", "1 suggestion", "Latest" share radius and caption size. | Keep. |

### Accessibility
- **Color contrast**: axe (WCAG 2.1 A/AA) reports 0 serious/critical in every state, theme and engine; key token pairs ≥ 4.5:1 (see [accessibility.md](accessibility.md)).
- **Touch targets**: 24 px icon buttons (desktop floor), 32 px form controls.
- **Text readability**: TR and DE fit without truncating controls; DE wraps the save status onto a second line under the title, which reads fine.

### What Works Well
- Collapsed cards + badges turn a 40-field form into a one-screen overview.
- The preview's German variant uses "Berufserfahrung", "März 2022 – heute" regardless of UI language.
- Every reversible act (remove entry, archive, rename, use / keep suggestion, add skill, restore version) gives an Undo toast; restore asks first and says the current version stays in history.
