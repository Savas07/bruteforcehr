## Design Critique: Version history

### Overall Impression
A readable timeline: day groups, a change sentence, source tag (You / Import), time, "Latest", and per-row Compare with now / Restore this version. The restore confirmation is exactly the reassuring copy research asked for. The compare dialog was a dead end, and removed lines were red.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| "Compare with now" shows the diff but has only Close: having confirmed "yes, that's the version I want", the user must close, find the row again and press Restore. | 🟡 Moderate | Put "Restore this version" (with the same confirmation) in the compare dialog's footer. |
| Removed lines are struck through on a red tint (`danger-subtle`); with green for added. A diff isn't an error, and the system keeps red for errors (Calm). | 🟡 Moderate | Neutral tints: removed on `surface-sunken` with strike-through and "−", added on `accent-subtle` with "+". Text labels for screen readers stay. |
| The diff list scrolls but isn't focusable (no controls inside), so keyboard users can't scroll a long diff. | 🟡 Moderate | Make it a focusable, labelled group. |
| In the real app the newest entry after a remote save reads just "Edited" (no section list) — `windows/cv-studio/history-light.png`. | 🟢 Minor | Comes from the revision's `diffSummary` written by the other device (the E2E writes none); app-written revisions say "Edited Header and Summary". |
| Times show only the clock ("1:05 PM") under a day heading; the full date is in the `title` tooltip and `<time datetime>`. | 🟢 Minor | Fine with day groups. |

### Visual Hierarchy
- **What draws the eye first**: the "Latest" pill, then the sentences. Correct.
- **Emphasis**: actions are plain buttons, so the timeline stays quiet.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Source | Shared `SourceTag`. | — |
| Diff tints | Red/green vs calm palette. | Fixed. |

### Accessibility
- **Color contrast**: fg-secondary on sunken 6.93 / 8.87:1; fg-primary on accent-subtle 15.x / 12.x:1 (allowed pairing).
- **Keyboard**: Restore confirmation is a Radix AlertDialog (Cancel first, Esc cancels).

### What Works Well
- Restore never destroys: it writes a new revision, and the confirmation says so.
- "Sent with applications" ties versions to where they were used.

### Priority Recommendations
1. **Restore from the compare dialog.**
2. **Calm diff colours and a keyboard-scrollable diff.**

## Resolution

| # | Finding | Severity | Status |
|---|---------|----------|--------|
| 1 | Compare dialog without Restore | Moderate | Fixed: `RestoreButton` is exported with a `prominent` variant; `Screen.tsx` passes it as the dialog's action; restoring closes the dialog and shows the "Restored the version from …" toast (shared `restore()` helper). |
| 2 | Red removed lines | Moderate | Fixed: neutral tints in `CompareDialog`; "−"/"+" marks, strike-through and sr-only "Removed:"/"Added:" unchanged. |
| 3 | Diff not keyboard-scrollable | Moderate | Fixed: `role="group"`, `tabIndex=0`, labelled by the summary line. |
| 4 | "Edited" without sections for remote saves | Minor | Logged (data from the other device). |
| 5 | Clock-only times | Minor | Logged. |
