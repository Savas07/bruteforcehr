# CV Studio — import (desktop) — accessibility audit

## Accessibility Audit: Import a CV (pick → read → review)
**Standard:** WCAG 2.1 AA | **Date:** 2026-10-23

Method: axe-core (WCAG 2.1 A/AA) on `import-{pick,reading,error,review}-{light,dark}-{webkit,chromium}` from the scratch harness with Firebase mocked (reports `artifacts/a11y/desktop/cv-studio/en/`); keyboard behaviour from the harness ("Next field to check", "Looks right") and the component tests (`ImportReview.test.tsx`, `ImportCvDialog.test.tsx`); contrast from `@bfhr/ui-tokens`. Screen-reader column is [INFERENCE] from roles, names and live regions.

### Summary
**Issues found:** 3 | **Critical:** 0 | **Major:** 2 (fixed) | **Minor:** 1 (fixed)

axe: **0 critical · 0 serious · 0 moderate · 0 minor** in all 16 reports, before and after. "Needs review" items are `aria-hidden-focus` on the content Radix hides behind the modal (expected) and nothing else.
