## Design Critique: Import

### Overall Impression
Honest and calm: a stepper, a time expectation while reading, "on our side, not your file" on failure, and a review that counts what needs a look without ever blocking Create CV. The weak spots were small but real: section names cut in the jump list, a reflex Esc throwing the review away, and focus lost after "Looks right".

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| The section jump list (176 px) puts "3 to check" on the same line as the name, so names truncate: "Experie…", "Educati…" in EN, worse in DE ("Berufserfahrung") and TR. The list is the map of the review; cut names defeat it. | 🟡 Moderate | Count under the name; let the name wrap. |
| Outside clicks are ignored during the review (good), but Esc closes the dialog and drops every edit and "Looks right" made so far, with no confirmation. | 🟡 Moderate | During the review, Esc doesn't close; the Close button (and Try another file) are the deliberate exits. |
| "Looks right" removes itself once pressed, so keyboard focus falls to the document body and the user loses their place. | 🟡 Moderate | Move focus to the field the user just confirmed. |
| Research's right-hand "original file" pane (source region highlighted per field) isn't built; the review shows the file name and "Kept attached to this CV". | 🟢 Minor | Later milestone (needs a PDF/DOCX viewer); the AI disclosure and per-field reasons cover trust for now. |
| No "Save as draft" (research footer). | 🟢 Minor | Create CV is always enabled and flags can be fixed later, so a draft adds little now. |
| The amber tint of a flagged field bleeds ~8 px past the right edge of its column (`-mx-2`). | 🟢 Minor | Cosmetic; tighten when the field grid is next touched. |

### Visual Hierarchy
- **What draws the eye first**: the summary card ("We read 32 fields. 5 need a quick look.") then the amber "1 to check" markers. Correct.
- **Reading flow**: summary → notes from reading → About this CV (name, language) → sections; the footer keeps Try another file (left) and Create CV (right, primary).
- **Emphasis**: amber is reserved for "Needs a look"; no red anywhere except a real validation error.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Confidence | Shared `ConfidenceTag` (dot + text + reason). | — |
| Progress | Shared `ProgressNote` with steps, same as the ATS check. | — |
| Errors | `InlineAlert` error with Try again + Try another file. | — |

### Accessibility
- **Color contrast**: warning-text on the 50 % warning tint 4.93:1 (light) / 5.32:1 (dark); labels fg-secondary 7.33 / 7.11:1.
- **Targets**: chips and buttons 24–32 px.
- **Text readability**: field hints in caption1 fg-tertiary (5.86:1).

### What Works Well
- Proceed-or-fix: nothing has to be fixed to create the CV.
- Notes from reading the file are concrete ("your file gives only the year here, so we kept just the year").
- Focus moves into each new step; the reading step has a time expectation and Cancel.

### Priority Recommendations
1. **Esc doesn't discard a review.**
2. **Keep focus after "Looks right".**
3. **Readable section names in the jump list.**

## Resolution

| # | Finding | Severity | Status |
|---|---------|----------|--------|
| 1 | Jump-list names truncated | Moderate | Fixed: the nav button is a column (name wraps, count below), `ImportReview.tsx`. |
| 2 | Esc discards the review | Moderate | Fixed: `onEscapeKeyDown` prevented while `stage.step === "review"` (`ImportCvDialog.tsx`); Close and Try another file still leave. |
| 3 | Focus lost after "Looks right" | Moderate | Fixed: confirming focuses the field's input. |
| 4 | Original-file pane | Minor | Logged. |
| 5 | Save as draft | Minor | Logged. |
| 6 | Tint bleed | Minor | Logged. |
