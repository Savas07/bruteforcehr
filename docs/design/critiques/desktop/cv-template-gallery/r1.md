## Design Critique: Template gallery

### Overall Impression
Live thumbnails of the user's own CV make the choice concrete, and every template being ATS-safe removes a worry. The gallery inherited the preview's rendering bug, and its keyboard focus and one swatch weren't visible enough.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Thumbnails share the preview's shadow-DOM rendering, so they showed the same wrong ink/accent/sizes (see live editor r1 #1); in dark mode the thumbnails were washed out. | 🔴 Critical | Fixed with the preview (`:root` → `:host`). |
| Each thumbnail is `aria-hidden` but contains the CV's real links (mailto, profiles): three focusable elements hidden from assistive tech (axe `aria-hidden-focus`, serious). | 🟡 Moderate | Make the thumbnail `inert`. |
| The template card's focus ring was `currentColor` (white/black, not the focus token) and showed on mouse clicks too (`focus-within`). | 🟡 Moderate | Ring on `:has(:focus-visible)` in `line-focus`, offset 2 px, like every other control. |
| The Graphite swatch (`#2D3340`) on the dark inspector had only a `line-subtle` edge (1.31:1), so it nearly disappeared (1.4.11). | 🟡 Moderate | Outline every unselected swatch in `line-control` (≥ 3:1). |
| At 1280 the inspector overlays the preview, so a template or accent change isn't visible on the big page while the Design tab is open. | 🟢 Minor | The thumbnails are live renders and update with the accent; closing the inspector (Mod+Shift+D) shows the page. At ≥ 1880 px it docks beside the preview. Revisit with a "Preview" toggle inside the tab if users ask. |
| Research proposed a modal gallery with Preview / Use buttons; the build applies on selection inside the inspector. | 🟢 Minor | Fine for 3 templates: a choice is one click to undo (pick the previous card) and every saved session is in Version history. Keep the modal for the M3 creation flow if the template count grows. |

### Visual Hierarchy
- **What draws the eye first**: the selected card (accent border + check + bold name). Correct.
- **Reading flow**: Template → Accent colour → Fonts → Paper → Spacing → Photo, top to bottom; each group has a heading.
- **Emphasis**: the one-line note "All templates are one column… application systems read every section" is quiet but present.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Focus ring | Card ring differed from the global `:focus-visible` style. | Fixed (token + offset). |
| Selection | Check icon + border + weight on cards; check + 2 px border on swatches; native radios for fonts. | — |

### Accessibility
- **Color contrast**: card descriptions are fg-secondary on `surface-sunken`: 6.93:1 light, 8.87:1 dark. Swatch outlines (`line-control`) 3.32:1 or more on every inspector surface.
- **Targets**: cards ~150 × 200 px; swatches 28 px (desktop).
- **Text readability**: card descriptions wrap to two lines; TR ("Tek sütun · Sık · Tek sayfaya daha çok sığar") fits the two-column grid at 340 px (`webkit/tr/template-gallery-light-1280x800.png`).

### What Works Well
- Thumbnails use the user's own data, never sample people (research open question 7).
- Choices are radio groups: one Tab stop per group, arrows move and apply.

### Priority Recommendations
1. **Thumbnails render with the template's variables** (shared fix).
2. **`inert` thumbnails** so hidden links aren't focusable.
3. **Token focus ring and visible swatch edges.**

## Resolution

| # | Finding | Severity | Status |
|---|---------|----------|--------|
| 1 | Thumbnails mis-rendered | Critical | Fixed (`PreviewPane.tsx` `shadowCss`). |
| 2 | Focusable links inside `aria-hidden` thumbnails | Moderate | Fixed: `inert` on the thumbnail wrapper (`DesignControls.tsx`). axe `aria-hidden-focus` 3 → 0. |
| 3 | Card focus ring colour / mouse focus | Moderate | Fixed: `has-focus-visible:outline-2 outline-line-focus outline-offset-2`. |
| 4 | Dark swatch edge | Moderate | Fixed: unselected swatches `border-line-control`. |
| 5 | Preview hidden behind the overlay inspector at 1280 | Minor | Logged. |
| 6 | Inspector tab instead of modal gallery | Minor | Logged (design decision kept). |
