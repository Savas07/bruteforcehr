## Design Critique: Jobs — after r5

### Overall Impression
The header is one search row plus one filter row in all three languages at 1280, Save search keeps its place, the sort is a real menu that explains the ranking, and an over-narrow search now shows exactly which filter to drop and what it would bring back. What was left after round 2 was alignment and wording.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| 1. Round 2: the pills sat 2 px above the centre of Save search (28 px pills top-aligned against the 32 px button). | 🟢 Minor | Pad the pill group by 2 px so its first line centres on the button. |
| 2. Round 2: DE at 1280 still wrapped one pill ("Quelle") onto a second line — 10 px short. | 🟡 Moderate | Use the shorter German word for the Posted facet, "Datum" (the popover lists the time ranges, so the meaning stays clear); the active pill reads "Datum: Letzte 7 Tage". |
| 3. Round 2: the chip count "+3" isn't explained to sighted users (screen readers got it in the name). | 🟢 Minor | Tooltip "Shows 3 more jobs" on the chip; the same text as the chip's accessible description, the name stays "Remove filter: Seniority: Intern". |
| 4. EN with two long active values ("Work mode: Remote", "Seniority (2)") wraps Clear all alone onto a second line at 1280. | 🟢 Minor | Accept: the bar wraps by design below its one-line width; Save search stays put. |
| 5. Sort menu: "Sort" label, ✓ Best match / Newest, the ranking note under a separator; the trigger reads "Sorted by Newest" after the change and the URL carries `sort=newest`. | — | Pass. |
| 6. Final matrix: populated, empty (first use), loading, error, offline × light / dark × 1280 / 1920 × WebKit / Chromium — no clipping, no overlaps; offline disables Search job sites with "Needs a connection" and keeps the filters working. | — | Pass. |

### Visual Hierarchy
- **What draws the eye first:** Save search and Apply; in zero results the chips (accent subtle) then "Remove all filters".
- **Reading flow:** unchanged from r5; zero results read title → body → chips → actions.
- **Emphasis:** "+3" is regular weight next to the medium label, so the filter name leads.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| DE vocabulary | "Datum" is the pill and popover title; the detail header keeps "Veröffentlicht gestern" (a sentence, not a filter name). | — |

### Accessibility
- **Color contrast:** unchanged tested pairings. axe: 0 critical · 0 serious · 0 moderate · 0 minor in all 40 reports (see `accessibility.md`).
- **Touch targets:** unchanged (pills / chips 28 px, sort 24 px).
- **Text readability:** unchanged.

### What Works Well
- DE, TR and EN fit the same two-line header at 1280.
- Removing a chip moves focus to that filter's pill, so keyboard users continue in the filter bar.

### Priority Recommendations
