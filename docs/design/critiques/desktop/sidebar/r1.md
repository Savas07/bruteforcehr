## Design Critique: Sidebar navigation (desktop) — round 1

Context: `src/components/Sidebar.tsx`: "Jump to…" (⌘K), Today · Jobs · Tracker · CVs · Mail · Insights, the active section's nested navigation, and the footer (update card, Settings, Keyboard shortcuts, sync line). Below 640 px it becomes a 60 px rail with tooltips. Research: `docs/design/research/desktop-chrome.md` → "Sidebar navigation" (Superlist, Todoist, LangChain) and the M6 addendum (Aboard, Canny, Snowflake). Stage: final polish.

Captures judged: every screen capture shows the sidebar; the chrome target adds `rail` and `rail-focus` (600 × 800, Tab to Today) in WebKit (macOS chrome) and Chromium (Windows chrome), light + dark, EN/TR/DE: `artifacts/screens/desktop/harness/{webkit,chromium}/{,tr/,de/}chrome-rail*-{light,dark}-600x800.png`. Keyboard probe in both engines ([keyboard-pass.md](../keyboard-pass.md)).

### Overall Impression

Calm and familiar: one flat list, a teal selected fill, utilities at the bottom. The real problem was invisible in screenshots: on macOS the keyboard couldn't reach the sections at all.

### Usability

| Finding                                                                                                                                                                                                                                                                     | Severity    | Recommendation                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| macOS: WKWebView's Tab skips links unless Safari's "Press Tab to highlight each item" is on, so Tab went "Jump to…" → "Keyboard shortcuts" → content and never reached Today…Insights or Settings (WebKit probe: 7 links unreached on every screen; Chromium reached them). | 🟡 Moderate | Turn on `tabFocusesLinks` for the app's WKWebView.                                                                                       |
| Every Tab cycle passes 9 sidebar stops before the content.                                                                                                                                                                                                                  | 🟢 Minor    | Keep: ⌘1–6 / `G` sequences jump to a section and focus its title, `nav` / `main` landmarks exist, and the order matches native sidebars. |
| The sync line's glyph sat 8 px left of the row icons above it.                                                                                                                                                                                                              | 🟢 Minor    | Align it with the rows.                                                                                                                  |
| Rail: the name and shortcut appear in a tooltip on hover and on keyboard focus (rail-focus capture); the accessible name comes from the hidden label.                                                                                                                       | —           | Pass.                                                                                                                                    |

### Visual Hierarchy

- **What draws the eye first**: the selected section's fill, then "Jump to…" with its keycaps. Correct.
- **Reading flow**: search → sections → (nested items) → footer utilities.
- **Emphasis**: no badges or promos (research rejected Wrike/Height-style cards); the update card only appears with a downloaded update.

### Consistency

| Element         | Issue                                                              | Recommendation |
| --------------- | ------------------------------------------------------------------ | -------------- |
| Labels in TR/DE | "Klavye kısayolları", "Tastenkürzel", "Lebensläufe" fit at 232 px. | —              |
| Selected state  | Teal fill (accent decision 2026-10-22), same in the rail.          | —              |

### What Works Well

- Keycaps on "Jump to…" teach ⌘K in place.
- The rail keeps every destination and both utilities.

### Priority Recommendations

1. **Make the sections reachable by Tab on macOS.**
2. Align the sync line.
