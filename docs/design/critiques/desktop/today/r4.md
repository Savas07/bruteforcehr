## Design Critique: Today (desktop) — round 4

Context: follow-up round after merging main (design-build locale / time zone pin `?locale=&tz=`). Scope: the "Pick a date…" snooze dialog. Same persona and stage as rounds 1–3.

Captures judged:
- `capture:design today --sizes 1280x800 --axe` (WebKit + Chromium, all states, light + dark): 20 screenshots in `artifacts/screens/desktop/harness/{webkit,chromium}/today-*-1280x800.png`, 20 axe reports in `artifacts/a11y/desktop/`.
- Probe of the date dialog with the browser's own zone set to `Pacific/Honolulu` and the page pinned to `?tz=Europe/Istanbul&locale=en-GB`, both engines.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| `SnoozeDateDialog` computed the earliest date from the real clock and the machine's zone (`Date.now()`, `toLocaleDateString`), and turned the picked day into 09:00 in the machine's zone. The rest of Today follows the model's `ctx.now` / `ctx.timeZone` (the user's profile zone), so the field could offer today, or snooze to 09:00 in the wrong zone, when the machine and profile zones differ. The design pin couldn't reach it either. | 🟡 Moderate | Build both from the model: `TodayModel.snoozeDate = { min, timeZone }` (tomorrow as `YYYY-MM-DD` in the user's zone) and a pure `snoozeDateInstant(day, timeZone)` (09:00 that day in that zone, daylight saving handled). |
| A typed date can bypass `min` in some engines, and Snooze then accepted today or a past day. | 🟢 Minor | Disable Snooze with a reason: "Pick tomorrow or a later day. For today, use Later today." |

### Accessibility
axe: 0 critical · 0 serious · 0 moderate · 0 minor in all 20 runs. The single WebKit "needs review" item is still the shell's ⌘ keycap (not Today).

## Resolution

| Finding | Status | Where |
|---|---|---|
| Min date / snooze instant from the machine clock and zone | Fixed: `TodayModel.snoozeDate` + `snoozeDateInstant` in `model.ts`; the dialog only reads them. Tests: tomorrow in Istanbul vs New York at 22:30 UTC; 09:00 in Istanbul, Berlin and New York on its daylight-saving change day. Probe: `min = 2026-10-23` in both engines with the machine zone set to Honolulu. | `b9d3bde` |
| Typed date before `min` | Fixed: Snooze disabled with the reason (EN / TR siz / DE du) | `b9d3bde` |

Exit: zero Critical and no unresolved Moderate findings.
