## Design Critique: Tracker board (desktop), round 4

### Overall Impression
Calm, quick and honest. The board reads stage by stage, every move shows exactly what changed with an Undo, and automatic changes carry their source and reason in the panel. No blocking issues remain.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Quill Docs opens with its follow-up suggestion; no crash in any engine or language (render test covers all 25 records). | ✅ | — |
| With the 400 px panel at 1280, two full columns stay visible next to the record, and the selected card scrolls into view (Lumenpay after Undo lands in Interviewing, highlighted, with Offer collapsed to a "0" rail). | ✅ | — |
| Keyboard: → / ↓ move focus, `M` opens the grouped "Move to…" menu with the current stage checked and Accepted/Declined greyed with the reason, Esc returns to the card, ⇧⌘→ moves it and keeps focus on it, Enter opens the panel. | ✅ | — |
| In DE, the peeking fourth column header truncates ("Eingang bestä…"). | 🟢 Minor | Log. Only in the peek slice; the header wraps (`text-balance`) once the column is in view. |
| Error state: the pane error floats over empty column wells without dimming them. | 🟢 Minor | Log. The real headers with "–" counts stay readable behind it, as states.md asks ("board pane error under real headers"). |

### Visual Hierarchy
- **What draws the eye first:** the title, then the stage headers; with the panel open, the record's role title. Correct.
- **Reading flow:** stages left → right, cards by next action; panel header → Up next → Timeline → Application.
- **Emphasis:** teal appears only for focus, the selected card, drop targets and the primary first-use action; phase dots stay small. Closed outcomes are grey; Accepted is the only green.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Shared components | `StatusMenu`, `InteractiveStatusPill`, `TimelineRow`, `NudgeCard`, `ApplicationSummaryBlock`, `DetailSidePanel`, `EmptyState`, `GhostRow`, `PaneError`, `StaleStamp`, `SyncGlyph`, `BoardCardSkeleton`, `Toast` used as specified. | — |
| Copy | "Not selected" / "No response" everywhere; move toasts "{company} · moved to {stage}", "· marked as not selected"; no exclamation marks. | — |

### Accessibility
- **Color contrast:** see [accessibility.md](accessibility.md) (axe, both engines, both themes).
- **Touch targets:** cards are full-size buttons; corner and collapse buttons 24 px.
- **Text readability:** TR and DE fit 272 px columns without truncating meaningful labels in view.

### What Works Well
- Drag states the exact transition before release and refused outcomes explain themselves without blocking.
- One Undo model everywhere: toast, ⌘Z / Ctrl+Z, and the panel's Undo on automatic changes, each leaving a visible "You" row.
- Empty board teaches the model (every stage present, first-use explainer in Saved) without a takeover.

### Priority Recommendations
None blocking. Minor items logged for the user's taste review.
