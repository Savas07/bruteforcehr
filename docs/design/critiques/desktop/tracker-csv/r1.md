## Design Critique: CSV import

### Overall Impression
Honest and forgiving: the file is read on the device, guesses are shown rather than applied silently, and nothing has to be perfect to import — rows that can't be imported are named with the reason and left out, duplicates start unticked, and one Undo removes exactly what was added. First pass issues were focus and alignment.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Opening on Columns (a file handed over) put focus on the Close button (tooltip showing), because autofocus only searched the step body while Continue sits in the footer. | 🟡 Moderate | Autofocus searches the whole dialog for `data-autofocus` (Continue). |
| "Your column" row headers were centered (`th` default), breaking the left edge the samples and selects follow. | 🟢 Minor | `text-start`. |
| Esc and outside clicks don't close after the File step, so mapping work isn't lost by reflex; Close stays available. | — | Keep. |
| "Characters / Separated by / Dates" are always visible rather than behind "Characters look wrong?". Slightly more chrome, but TR/DE Excel exports are the common case and the detected values reassure. | 🟢 Minor | Keep visible. |
| Review notes truncate in the last column at 960 px dialog width (full text in tooltip; "Show only rows with notes" filters to them). | 🟢 Minor | Accept. |
| Workbook dropped by mistake: plain explanation with the exact menu paths for Excel, Numbers and Google Sheets. | — | Keep. |

### Visual Hierarchy
- **What draws the eye first**: the step's question ("Match your columns to ours…", "What do your status words mean?", "7 of 9 rows are ready to import.").
- **Emphasis**: unmapped status words get a warning tint and an inline alert; blocked rows use warning text, never red; the primary button carries the count ("Import 6 applications").

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Dialog shell, stepper, drop zone | Same as CV import (`ImportCvDialog`). | — |
| Status pills | Shared `StatusPill` in Statuses and Review. | — |
| Undo | Shared toast; Undo deletes the created applications (their events are removed server-side). | — |

### Accessibility
- **axe**: 0 critical · 0 serious · 0 moderate for every step × theme × engine.
- **Keyboard**: native selects and checkboxes; Mod+Enter imports on Review; focus moves to each new step.
- **Labels**: each select is labelled by its file column / status word; row checkboxes "Import row 3: Kervan Teknoloji, Frontend Geliştirici", described by the row's notes.

### What Works Well
- Turkish Windows-1254 and German Windows-1252 exports read correctly without user action; UTF-16 TSV too.
- The app's own export re-imports with every column and status recognized (round-trip test in `tracker-table/model.test.ts` and the E2E).

### Priority Recommendations
1. **Focus Continue, not Close, when the dialog opens on a later step.**

## Resolution

| # | Finding | Severity | Status |
|---|---------|----------|--------|
| 1 | Focus lands on Close | Moderate | Fixed: `onOpenAutoFocus` searches the dialog content for `[data-autofocus]`. |
| 2 | Centered row headers | Minor | Fixed: `text-start`. |
| 3 | Always-visible read options | Minor | Kept by decision. |
| 4 | Truncated review notes | Minor | Accepted (tooltip + filter). |
