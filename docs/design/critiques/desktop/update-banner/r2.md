## Design Critique: Update banner, "Check for Updates…" and "Update required" (desktop) — round 2

Context: Turkish (siz) and German (du) pass, UX copy review (`skill://ux-copy`) and a keyboard / screen-reader probe, after the round 1 fixes.

Captures judged:
- `capture:design update --axe` (EN, light + dark) and `capture:design update --locale tr|de --themes light,dark --axe`: 17 states × 2 engines × 2 themes per language = 204 PNGs in `artifacts/screens/desktop/harness/{webkit,chromium}/{,tr/,de/}update-*.png`, 204 axe reports.
- Keyboard / accessibility-tree probe in both engines (Playwright, keyboard only): card → Later → collapsed line → expand; What's new → Tab cycle → Esc; check dialog retry; gate Tab cycle, Esc, ⌘K/Ctrl+K; 640 px (≈ 200 % zoom) for the notes dialog and the gate.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| German release-notes footer: "Release-Seite auf GitHub" + "Schließen" + "Neu starten und aktualisieren" don't fit 520 px; the primary button is cut off at the dialog edge. | 🟡 Moderate | 560 px dialog and a wrapping footer (`flex-wrap`, link `mr-auto`), so the link moves above the buttons when needed. |
| Turkish collapsed line: "Güncelleme h… 0.1.1" — the trailing version from round 1 truncates the title again. | 🟡 Moderate | Visible text is the title only; the button's name carries the version ("Update ready: version 0.1.1", `aria-label`, label-in-name holds). |
| "Later" removes itself and the expanded card's buttons on collapse, so keyboard focus fell to `<body>`; expanding did the same. | 🟡 Moderate | Focus follows the toggle: Later → collapsed line, collapsed line → Later. |
| Closing a dialog returned focus to `<body>`: the dialogs have no Radix trigger (they open from the menu, the palette, the card). | 🟡 Moderate | The controller remembers the element that had focus when the first dialog opened and restores it in `onCloseAutoFocus`. |
| Turkish card title wraps to two lines beside "Sonra". | 🟢 Minor | Reads fine; the card grows by one line. Keep. |
| Release notes stay English in Turkish and German. | 🟢 Minor | They are the GitHub release's Changesets notes, written in English for every release; the dialog chrome and date are localized. Keep. |
| The design "Save first" state named an invented CV in English in every language. | 🟢 Minor | Use the persona's base CV through the CV editor's own localized label ("“Base CV — English” CV'si", "Lebenslauf „Base CV — English“"). |

### UX copy
| Element | Before | After | Why |
|---|---|---|---|
| Save-first dismiss | Cancel | **Keep editing** (TR "Düzenlemeye devam edin", DE "Weiter bearbeiten") | Confirmation buttons name the action; "Cancel" could read as "cancel the update". |
| Failed install, card vs. dialog | "Update didn't install" / "Couldn't install the update" | **Couldn't install the update** in both | Same term for the same thing. |
| Card body | — | "Version 0.1.1 is downloaded. Restart when it suits you, or it installs when you quit." | Says what happened, that there's no hurry, and what happens otherwise (BRIEF §7 install-on-quit). Matches the research copy. |
| Errors | — | What happened + what to do + reassurance ("Your current version keeps working.") | Calm tone for a stressful product; never red, icon + text. |
| Gate | — | "BruteForceHR 0.1.0 is no longer supported. Update to version 0.2.0 or later to keep using it. Your data stays safe in your account." | States the versions, the way out, and the worry a user would have. |

German uses du ("Starte neu, wann es dir passt"), Turkish uses siz ("Size uygun olduğunda yeniden başlatın"), German ellipses keep the catalogue's spaced style ("Suche nach Updates …").

### Accessibility
- axe: 0 critical · 0 serious · 0 moderate · 0 minor in all 204 runs.
- Keyboard and names: see [accessibility.md](accessibility.md).

### What Works Well
- The card, dialogs and gate hold up in all three languages at 1280 px and at 640 px (200 % zoom) without clipping, after the two fixes above.
- The rail icon now carries a visible dot and a full name ("Update ready: version 0.1.1").
