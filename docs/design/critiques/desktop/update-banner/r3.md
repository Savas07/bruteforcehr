## Design Critique: Update banner, "Check for Updates…" and "Update required" (desktop) — round 3 (real apps)

Context: the same 17 update states in the real Tauri shells: WKWebView on macOS and WebView2 on Windows, design build (`pnpm build:e2e:design`), captured by `e2e/capture/capture-design.e2e.ts`.

Captures judged: CI run [39877756844](https://github.com/Savas07/bruteforcehr/actions/runs/39877756844) (`gh workflow run desktop.yml -f design_capture=true -f screens=none -f update_states=all`, commit `5198f62`), artifacts `desktop-design-screens-{macos,windows}-latest`: 17 states × light + dark per OS = 68 PNGs (`artifacts/screens/desktop/{macos,windows}/design/update-*.png`). Windows' hosted display is 1024×768, so its 1280×800 captures are taken at 75 % zoom (e2e/capture/helpers.ts).

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| In the real apps the gate and the dialogs said "BruteForceHR 0.0.0": the design states took the current version from the shell (the unreleased build's own `package.json` version), while the harness showed the persona's 0.1.0. | 🟢 Minor | The design states pin the persona's installed version (0.1.0) in both; production still reads the shell's version. |
| Window controls under the gate (not visible in WebDriver captures, which show the webview only): on macOS the traffic lights are native and drawn above the webview, and the gate keeps a 52 px `data-tauri-drag-region` row; on Windows the native title bar sits outside the webview. So the window can always be moved, minimised and closed while blocked (by construction, `window.rs` + `UpdateRequired.tsx`). | — | Pass. |

### Visual Hierarchy / Consistency
- WKWebView and WebView2 match the harness: card, collapsed line, rail dot, dialogs and the gate have the same layout, wrapping and colours as WebKit / Chromium in Playwright. German / Turkish lengths were covered in round 2.
- Dark mode on Windows: the notes dialog's elevated surface separates from the scrim; the primary button keeps its contrast.

### Accessibility
No new findings; see [accessibility.md](accessibility.md). The real-app E2E suite also proves the capability boundary: the updater plugin's own commands are refused ("not allowed"), `update_status` answers `idle / stable`, `restart_to_update` without a download is `no-update-ready`, and an unknown channel doesn't deserialize (CI run [39876711029](https://github.com/Savas07/bruteforcehr/actions/runs/39876711029), macOS + Windows).

## Resolution

| Finding | Status | Where |
|---|---|---|
| Current version in the design states | Fixed: `CURRENT = "0.1.0"` in the design provider | `src/design/updates.tsx` |

Exit: zero Critical and no unresolved Moderate findings across rounds 1–3.
