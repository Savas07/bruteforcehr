# Settings › Application answers (iOS) — critique round 1

- **Screen / goal / persona / stage:** the answers library behind the apply kit (BRIEF §4.4.3 "answers library", ADR 0002 `users/{uid}/answers`): work authorization, notice period, salary expectation, links and Q&A, each with per-language text and country tags. Final round for M4 Apply on iPhone.
- **Captures judged:** `capture.sh --screen settings --state populated --arg -BFHRSettingsPage --arg answers` on iPhone 17e, light and dark, before and after the fix. Live: `apply-live-check.sh` seeds 6 answers and checks they're intact after the kit (PASS).

## Design Critique: Application answers (iPhone)

### Overall Impression

An intro line says what the library is for and how the kit picks rows; answers are grouped by kind, each row with its text and a compact "TR · EN, TR" line for countries and languages. Add is a "+" in the navigation bar; rows open the editor; swipe deletes with Undo.

### Usability

| Finding                                                                                                            | Severity    | Recommendation                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. "Reorder" and "+" together in the navigation bar truncated the page title to "Application answ…" on iPhone 17e. | 🟡 Moderate | **Fixed:** Reorder is a row under the intro (shown with 2+ answers); while reordering, the bar shows only "Done". The full title fits (`AnswersLibraryPage.swift`). |
| 2. Two rows can share a label ("Work authorization" for TR and EU).                                                | 🟢 Minor    | Kept: the country line tells them apart, and the kit only shows the one for the job's country.                                                                      |

### Visual Hierarchy

- **First:** the title, then the intro, then the first group.
- **Emphasis:** no filled buttons on the page; the editor sheet holds the primary (Save).

### Accessibility

- Group headers are headers; each row reads label, text and the country/language line.
- Swipe-to-delete also has the editor's Delete; Undo toast after either.

## Resolution

Zero Critical, zero open Moderate: Moderate 1 fixed and re-captured. Minor 2 kept.
