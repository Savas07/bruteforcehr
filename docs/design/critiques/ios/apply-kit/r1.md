# Apply kit (iOS) — critique round 1

- **Screen / goal / persona / stage:** the kit after "Open company site" (BRIEF §4.4.3 external link, research/apply.md "Decision — iOS"): the CV file, the cover letter and the answers library ready to copy while filling an ATS form, then "Did you apply?". Final round for M4 Apply on iPhone.
- **Captures judged:** `capture.sh --screen apply --arg -BFHRApplyStep --arg kit` on iPhone 17e, light and dark, before and after the fixes. Live: `apply-live-check.sh` copied a kit row and answered "Yes, I applied" (check "Applied: status applied, channel external_link" PASS).

## Design Critique: Apply kit (iPhone)

### Overall Impression

One sentence says what the page is for, then the CV file with Save to Files / Share, the cover letter with Copy text / Share PDF, and the answers rows, each with Copy. "Open company site" stays in the sticky bar until the user comes back.

### Usability

| Finding                                                                                                                           | Severity    | Recommendation                                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. The cover letter's share row read "Share Your cover letter, PDF": it reused the VoiceOver file description as a visible label. | 🟡 Moderate | **Fixed:** visible label "Share cover letter PDF" (EN/TR/DE in `Apply.xcstrings`); VoiceOver keeps the descriptive label.                                        |
| 2. "Save to Files" wrapped onto two lines next to a one-line "Share" on iPhone 17e (unequal buttons).                             | 🟡 Moderate | **Fixed:** the two file actions stack full width (`KitFileRow`).                                                                                                 |
| 3. The page doesn't say which answers are hidden for this job's country.                                                          | 🟢 Minor    | Kept: `AnswersKit.answers` shows only the rows for the job's country, currency and language; the full library is one tap away in Settings › Application answers. |

### Visual Hierarchy

- **First:** the instruction line, then the CV file (the thing most forms ask for first).
- **Emphasis:** the bar's "Open company site" is the only filled button.

### Consistency

| Element     | Issue                                                                | Recommendation |
| ----------- | -------------------------------------------------------------------- | -------------- |
| Copy toasts | Name what was copied ("Notice period copied"), like the desktop kit. | —              |

### Accessibility

- Each file row is one element: "Your CV, PDF, 84 KB"; actions are separate buttons with full names.
- Touch targets ≥ 44 pt; see `../tailor-review/accessibility.md` for the audit suite.

### What Works Well

- Save to Files explains why ("so the form's Choose file finds your CV").
- The kit keeps the user in the app between Safari visits; "Did you apply?" closes the loop.

## Resolution

Zero Critical, zero open Moderate: Moderates 1 and 2 fixed and re-captured (light, iPhone 17e). Minor 3 kept.
