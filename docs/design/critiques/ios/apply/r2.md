## Design Critique: Apply

### Overall Impression
The checklist does what the research asked: one screen, best defaults preselected (the CV the match
is based on, no letter, the posting's own route first), and a button that names the next step. The
Critical from r1 (the email body claimed a cover letter that wasn't attached) is gone. The flow
end to end now works on live data: Safari → "Yes, I applied" → Applied with the CV revision pinned.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Live: coming back from Safari reopened the sheet on the checklist instead of the kit with "Did you apply?" (the sheet's model was rebuilt on re-render) | 🔴 Critical | Keep one model per opened sheet (found by the live run; fixed before this round's captures) |
| Kit / email: VoiceOver read the file row as "Deniz-Aksoy-CV.pdf" (audit: "Label not human-readable") | 🟡 Moderate | Read what it is: "Your CV, PDF"; Share says "Share Your CV, PDF" |
| Cover letter section header and row label both say "Cover letter" | 🟢 Minor | Inset-grouped picker convention; Log |
| Empty (no CV): "Add a CV first." sits above a disabled "Open company site" | 🟢 Minor | Correct blocker order; "Open CVs" is in the CV section. Keep |
| Email send button wraps a long address onto two lines | 🟢 Minor | r1 decision (verb kept, address in full). Keep |

### Visual Hierarchy
- Checklist: CV (with band pill) → Cover letter → Send via (radio list with source lines) → one primary.
- Kit: the "Did you apply?" card first, then the files; primary "Open company site again" with the host as subtitle.
- Email: From → To → Subject → Message → footer about the 10-second undo → Attachments → "Send to …".

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| SubmitPrompt | Same component and copy as Job detail's card | None |
| Toasts | "… · marked as Applied · Undo", "Sending to … in 10 s · Undo" follow D11/D12 | None |
| Bottom bar | Capped at AX1 with the Large Content Viewer, like Job detail's Apply bar | None |

### Accessibility
- Xcode audits pass on checklist (default + AX5), kit with prompt, email (see `accessibility.md`).
- All buttons ≥ 44 pt; radio rows expose `.isSelected`; the header combines role + company.

### What Works Well
- Route rows show where each one goes ("apply.workable.com · opens here in Safari").
- "Did you apply?" is inline and never blocking; "I'm not applying" moves back to Saved quietly.
- Email from a connected account says up front that Send can be undone for 10 seconds.

### Priority Recommendations
1. **Keep the sheet's state across Safari** (Critical, fixed).
2. **Readable file labels for VoiceOver** (fixed).
