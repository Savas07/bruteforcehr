# Attachment picker (iOS) — critique round 1

- **Screen / goal / persona / stage:** "Add attachments" from the email composer (BRIEF §4.4.3 email, research/apply.md "iOS: attachment picker"): pick saved files (multi-select with an "Add N selected" tray) or From Files…, within the account's size limit and the 5-file cap. Final round for M4 Apply on iPhone.
- **Captures judged:** `capture.sh --screen apply --arg -BFHRApplyStep --arg attach` on iPhone 17e, light and dark, before and after the fix.

## Design Critique: Attachment picker (iPhone)

### Overall Impression

A medium-detent sheet with "Your files" (name, type, size, date), then From Files… and the provider's limits in the footer; the tray with "Add N selected" appears once something is picked.

### Usability

| Finding                                                                                                                                                                 | Severity    | Recommendation                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. The sheet used the default glass background: the composer's text and its teal Send button showed through the file rows at the medium detent, lowering text contrast. | 🟡 Moderate | **Fixed:** `.presentationBackground(BFHRColor.groupedBackground)`, the app's convention for list sheets (CV export, history, template picker).     |
| 2. No Add button until something is selected.                                                                                                                           | 🟢 Minor    | Kept per research (Shopify-style tray): Cancel is always there; the tray names the count and blocks with the reason when a limit would be crossed. |
| 3. Long file names wrap to two lines.                                                                                                                                   | 🟢 Minor    | Kept: full names matter when several CV versions look alike.                                                                                       |

### Visual Hierarchy

- **First:** "Your files" — most attachments are the user's own rendered PDFs.
- **Emphasis:** the tray's filled "Add N selected" is the only primary.

### Accessibility

- Rows are radio-style toggles with selected state announced; limits are in text, not color.
- After the fix, row text sits on an opaque grouped background in both themes.

## Resolution

Zero Critical, zero open Moderate: Moderate 1 fixed and re-captured. Minors kept.
