## Design Critique: Version conflict and Compare

### Overall Impression
The banner states what happened, when, and that nothing is lost; the two choices are explicit and Compare is one tap away. At AX5 the Compare rows squeezed the value into a narrow column beside the label.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| AX5 Compare: "Other device, 10:30 AM" label column leaves a 2-word-wide value column | 🟡 Moderate | Stack label above value at accessibility sizes |
| Copy can't name the other device (revisions don't record one) | 🟢 Minor | "A newer version was saved there at {time}" — honest without the device name |

### Visual Hierarchy
- **First**: banner title; Keep this version filled, Use the other version outlined, Compare as a text button.

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| Buttons | ButtonPair stacks at long DE labels | — |

### Accessibility
- Not colour-only: struck text plus labels. Contrast and targets pass.

### What Works Well
- No red; calm copy in all three languages.

### Priority Recommendations
1. Stack labels at AX sizes (done).
