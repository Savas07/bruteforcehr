## Design Critique: CV editor (iOS), round 3

### Overall Impression
The round-2 fixes land cleanly: the loading skeleton keeps the (redacted, disabled) Edit · Preview bar so nothing jumps, the first-use list has one way in, the pushed error offers Try again and Go back. The screen is consistent across themes, devices and text sizes; what remains is minor polish and items that belong to later milestones.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| ✦ Improve: while typing into "Your value for [X%]" the keyboard hides the suggestion, so the user fills the blank without seeing the sentence it goes into. | 🟢 Minor | Show the resolved sentence under the field ("Drove … by 35%."), or scroll the selected suggestion above the field on focus. Logged for M2 (when Improve gets real suggestions). |
| Preview at fit-to-width is small on the 17e (page text ≈ 5–6 pt); "Actual size" is one tap away in the toolbar. | 🟢 Minor | Keep; pinch zoom comes with the cv-render page in M2. |
| Version history rows aren't tappable yet (no revision viewer / Restore). | 🟢 Minor | Logged: viewer and Restore are CV Studio (M2) per the research; the sheet says nothing is lost meanwhile. |

### Visual Hierarchy
- **What draws the eye first**: name (Edit), the page (Preview), the title + Try again (error) — correct in each state.
- **Reading flow**: unchanged from round 2; AX5 keeps every row's full text.
- **Emphasis**: one primary action per state (Start from scratch / Try again / Use suggestion).

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| Skeleton | Uses the shared redaction; the segmented bar is redacted like the rows. | Keep. |

### Accessibility
- **Color contrast**: all list text on tokens; audit results in `accessibility.md`.
- **Touch targets**: ≥ 44 pt.
- **Text readability**: no truncation in the editor at AX5.

### What Works Well
- The trust patterns hold end to end: Remove → toast with Undo → "Restored"; Use suggestion → "Suggestion applied" with Undo; AI blanks block use until filled.
- Dark mode, AX5 and both devices need no special layouts beyond the ✦ action bar.

### Priority Recommendations
1. **Resolved-sentence preview under the blank field** (M2).
2. **Revision viewer + Restore** (M2, CV Studio).
3. **Pinch zoom on the page** (M2, with cv-render).
