## Design Critique: Export options

### Overall Impression
Format, paper and file name in one short sheet; the default name `First-Last-CV.pdf` comes from cv-render. The audit flagged a clipped "Paper" label and near-failing footer contrast.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| "Paper" menu-picker label clipped (audit) | 🟡 Moderate | Segmented A4 / Letter with a "Paper" header, like Format |
| Title "Export…" kept the menu ellipsis | 🟢 Minor | Sheet title "Export" |
| Format footer contrast nearly passed; one clipping report | 🟡 Moderate | Token footer style; let the footer wrap fully |

### Visual Hierarchy
- **First**: Format segmented control; Share in the confirmation position.

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| Pickers | Mixed menu/segmented | Both segmented |

### Accessibility
- After fixes: contrast passes, no clipping at default or AX5.

### What Works Well
- Footer explains each format in plain words (ATS-readable PDF, Word for forms, JSON to back up).

### Priority Recommendations
1. Segmented paper (done). 2. Token footer + wrap (done). 3. Title without ellipsis (done).

## Resolution
All three changes made. The audit still reported the format explanation (as a footer) and then the one-line file-name field as clipped, so the explanation is now a row in the Format section, the field grows vertically (`axis: .vertical`) and the sheet opens at the large detent (everything fits without scrolling inside a half sheet). `testExportSheet` (default + AX5): 0 open issues.
