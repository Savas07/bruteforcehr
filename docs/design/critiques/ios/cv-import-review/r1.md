## Design Critique: Import review

### Overall Impression
"Did we read your CV correctly?" with a factual summary ("We read 82 fields. Fields to check: 2.") and amber flags, never red; Create CV is always enabled. The question as the inline nav title truncated in German.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| DE nav title "Haben wir deinen Lebensla…" truncated | 🟡 Moderate | Short nav title ("Import a CV"); the question becomes the screen's heading in the summary card |
| Design empty state showed only Start from scratch (design importer missing in the empty dataset) | 🟢 Minor | Give the empty design scenario an importer so the real empty state (Import a CV + Start from scratch) is captured |

### Visual Hierarchy
- **First**: the question heading, then the counts, then the flagged-only toggle; Create CV filled at the bottom.

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| Sections | Same section list and edit sheets as the editor | — |

### Accessibility
- Flags: info glyph + text reason + amber tint (not colour only). Heading has the header trait.

### What Works Well
- Opening a flagged entry resolves its flag; nothing is saved until Create CV.

### Priority Recommendations
1. Short title + in-content heading (done). 2. Design importer for empty (done).
