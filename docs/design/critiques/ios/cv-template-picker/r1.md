## Design Critique: Template picker

### Overall Impression
Thumbnails show the user's own CV in each template (no sample people), each "ATS-safe", with a clear checkmark on the current one. At AX5 the 2-column grid broke names mid-word.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| AX5: "Clas-sic", "Mod-ern" hyphenated in a 2-column grid; descriptions one word per line | 🟡 Moderate | One column at accessibility sizes |
| Default form header/footer used system secondary (contrast "nearly passed") | 🟢 Minor | Use the token header/footer styles |

### Visual Hierarchy
- **First**: the selected thumbnail (accent border + checkmark) — correct.
- **Flow**: templates → Look (accent, fonts, spacing, paper) → Done.

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| Section headers/footers | System colours vs tokens elsewhere | `cvListHeader()` / `cvListFooter()` |

### Accessibility
- **Contrast**: passes after token styles. **Targets**: swatches 44 pt. **Selection**: `isSelected` trait, not colour only (checkmark).

### What Works Well
- Names and descriptions localized from cv-render (TR/DE checked).

### Priority Recommendations
1. One column at AX sizes (done). 2. Token header/footer (done).

## Resolution
`LazyVGrid` uses one column when `dynamicTypeSize.isAccessibilitySize`; headers/footers use the shared styles. Audit default + AX5: 0 open issues.
