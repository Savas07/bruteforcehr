## Design Critique: Data & privacy

### Overall Impression

Native and calm: inset-grouped sections, the export's progress in the row, Save to Files and Share once the ZIP is on the phone, and deletion on its own pushed screen with the list of what goes. Round 1 found two moderate problems (no new export while one is ready; the delete screen froze scrolling while deleting, hiding the progress) and duplicated grey text in the confirm field.

### Usability

| Finding | Severity | Recommendation |
| --- | --- | --- |
| With an export ready, there was no way to make a fresh one (after editing CVs) until it expired 7 days later, while the footer says "Making a new export replaces it." | 🟡 Moderate | "Create export" row under the ready card. |
| While deleting, the whole list was `.disabled`, which also stopped scrolling and VoiceOver navigation; the progress label on the button could be off screen. | 🟡 Moderate | Disable only the controls (export first, re-auth, field, Keep); the list scrolls. |
| The empty confirm field showed the label again as its grey prompt ("To confirm, type DELETE") right under the same label. | 🟢 Minor | Empty prompt; the label above names the word. |
| Design fixture file name differed from the server's (`bruteforcehr-export-…` vs `BruteForceHR-export-…`). | 🟢 Minor | Fixture and fallback use the server's name. |
| "Keep my account" is the filled primary button and "Delete everything" the tinted destructive one below it; Return in the field only closes the keyboard. | — | Keep (safe action first, Fireflies / research). |
| Too large uses a warning tone with Open GitHub; too soon / daily limit are information; a failed request is an error with Try again. | — | Keep; desktop aligned to the same tones. |

### Visual Hierarchy

- **Page**: Export everything (description → action / progress / ready card) → Included → Not included → Delete account last, as destructive text in its own group (Monzo).
- **Delete screen**: large "Delete your account?" → itemized list with neutral trash glyphs → "This can't be undone." (semibold) → Export my data first → Confirm it's you (when needed) → the field → Keep my account / Delete everything.

### Accessibility

See `accessibility.md` (XCUITest `performAccessibilityAudit`, Dynamic Type AX5, VoiceOver).

### What Works Well

- The ready card states size and local expiry, and Save to Files / Share appear only once the file is downloaded.
- Re-authentication happens in place, names the address, and keeps the typed word.
- After deletion the app returns to the welcome screen with one calm line: "Your account and all its data were deleted."

### Priority Recommendations

1. Create export from the ready state.
2. Keep the delete screen scrollable while deleting.
