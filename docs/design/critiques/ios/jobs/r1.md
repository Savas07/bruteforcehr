## Design Critique: Jobs feed

### Overall Impression
The feed already reads like the research: Glassdoor-style rows with salary provenance, the band
pill instead of a number, Upwork scope chips and a LinkedIn chip row, in a calm teal-on-grey that
holds in dark mode. The biggest problems are small truth-and-noise issues in the row and the search
outcome copy, not the structure.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Row line 2 repeats the work mode when the place already states it: "Pixelpost · Berlin (Mitte), hybrid · Hybrid" — the first row of the first viewport, every theme | 🟡 Moderate | Leave the work mode out when the place already contains it (case- and diacritic-insensitive, localized label) |
| Search finished card: "Not searched: Adzuna (needs an API key)." — developer jargon; the user can't add a key and reads it as something they must fix | 🟡 Moderate | Plain reason: "not set up yet" (TR "henüz ayarlanmadı", DE "noch nicht eingerichtet") |
| Filter sheet › Posted: "Last 1 days" | 🟡 Moderate | Special-case one day: "Last 24 hours" (TR "Son 24 saat", DE "Letzte 24 Stunden") |
| Result header reads "Jobs: 37" rather than research's "37 jobs" | 🟢 Minor | Keep: the catalogs use the plural-free "Label: N" form everywhere (job detail "Requirements: 2 of 3 met", approved M0); no plural variations exist yet |
| First viewport on the 17e shows ~2.5 rows: two chip rows plus a ~40 pt gap above the header | 🟢 Minor | The gap is the inset-grouped section spacing; acceptable while the chip rows carry scope and filters (research decision §2–3) |
| Toolbar bell for Saved searches can read as "notifications" | 🟢 Minor | The label is "Saved searches" for VoiceOver and long-press; the bell matches the alert purpose (Glassdoor "Job alerts"). Log |
| Search failed (rate limited): InlineAlert sits inside a white list card — card in a card | 🟢 Minor | Cosmetic; same container rule as other inline alerts in lists. Log |
| Paste-a-link, empty: the disabled "Read the posting" row looks like a second placeholder field | 🟢 Minor | Disabled until a link is pasted (WCAG 1.4.3 exempts inactive controls); becomes accent once enabled. Log |
| Import review: "Location · Needs a look · Check this" squeezes the label beside the tag | 🟢 Minor | Readable; revisit if TR/DE wraps badly at AX sizes |

### Visual Hierarchy
- **What draws the eye first**: the large "Jobs" title, then the selected teal "All matches" chip, then the first row's title — correct for a feed.
- **Reading flow**: search → scope → filters → count/sort → rows; each row title → company/place → salary with provenance → band, age, sources.
- **Emphasis**: the band pill is the only filled color in the row; bookmark in accent; secondary lines in `Fg.secondary`. Good restraint.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Copy | "Not for me", "Hidden · Undo · Tell us why" match D19; "Saved" scope matches D10 | None |
| Chips | Scope chips (filled when selected) and filter chips (outlined, ▾) are distinguishable without color alone (fill + chevron) | None |
| Sheets | Filter sheet uses the same section-header color (`Fg.secondary`) as Job detail | None |

### Accessibility
- **Color contrast**: row text uses `Fg.primary` / `Fg.secondary` (17.4 / 10.1:1 light, 15.2 / 10.9:1 dark); "Salary not stated" uses `Fg.tertiary` #5E6573 (5.9:1 on white; #8F97A4 on dark, 6.6:1); band pill `Accent.text` on `Accent.subtle` 7.2:1.
- **Touch targets**: bookmark, chips, sort, ⓘ, + all ≥ 44 pt.
- **Text readability**: row title capped at 2 lines at default size, unlimited at AX sizes (checked in the matrix round).

### What Works Well
- Salary provenance on every row ("from employer" / "estimate" / "Salary not stated") — the Glassdoor trust cue.
- "Searching job sites for “frontend”…" then a calm outcome card with what was and wasn't searched.
- The import sheet says what happens before anything is saved ("You check them before anything is saved").

### Priority Recommendations
1. **Stop repeating the work mode in rows** — noise in the most-read line.
2. **Plain skipped-source copy** — no "API key" in user-facing text.
3. **"Last 24 hours"** — fix the visible grammar slip in the filter sheet.

| Finding | Severity | Resolution |
|---------|----------|------------|
| Work mode repeated in row | 🟡 Moderate | **Fixed** in 5c5df20 (`JobRowView.subtitle`) |
| "needs an API key" | 🟡 Moderate | **Fixed** in 5c5df20 (`jobs.search.skip.noKey`: "not set up yet", TR/DE) |
| "Last 1 days" | 🟡 Moderate | **Fixed** in 298cf91 (`jobs.posted.day`: "Last 24 hours", TR/DE) |

| Bell icon | 🟢 Minor | **Rejected**: labelled "Saved searches"; logged |
| Card in card for search failure | 🟢 Minor | Logged |
