## Design Critique: Jobs feed

### Overall Impression
The r1 fixes hold in every state: rows no longer repeat the work mode, the search outcome speaks
plainly ("not set up yet"), and the empty, loading, error and offline states use the shared
patterns. Two layout problems only show at the largest text size and one bit of duplicated copy in
the import review; none affect the default size.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| AX5: the result header squeezes "Best match" into the trailing half and breaks it mid-word ("Best / mat / ch") next to "Jobs: / 37" (17e, both themes) | 🟡 Moderate | At accessibility sizes put the count on its own line and the sort + ⓘ under it |
| Import review: the low-confidence field shows two labels for one meaning ("Needs a look" tag + "Check this") and squeezes the field label beside them | 🟡 Moderate | One signal: the shared `ConfidenceTag` ("Needs a look"), no second line |
| Empty (no account data): the first-use state only offers "Add a job from a link"; the search field above is the other entry and isn't named in design mode | 🟢 Minor | Live builds show `jobs.firstUse.body` ("Search for a role above…"); design mode has no search service. Keep |
| Offline: the chips and rows stay interactive; Save works offline (queued), Search job sites says it needs a connection | 🟢 Minor | Matches states.md (cached data wins, writes queue). Keep |
| Third scope chip ("Istanbul · hybrid") is cut at the trailing edge with no fade | 🟢 Minor | Standard horizontal scroll; the cut chip signals more. Log |

### Visual Hierarchy
- **What draws the eye first**: title → selected scope chip → first row title, in every state.
- **Reading flow**: unchanged from r1; at AX5 the rows stack (bookmark below the text) and the header now stacks too.
- **Emphasis**: teal only on the selected chip, band pill, bookmark and sort; error and offline states stay neutral grey (never red).

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Error state | `PaneError` with Try again + Copy details, same as Today/Job detail | None |
| Offline | `ConnectionBannerSection` first in the list, same as the Tracker | None |
| Skeleton | Real row layout with placeholder text (states.md) | None |

### Accessibility
- **Color contrast**: unchanged from r1 (all text ≥ 4.5:1 in both themes; band pill 7.2:1).
- **Touch targets**: chips, bookmark, sort, ⓘ, + ≥ 44 pt at every size.
- **Text readability**: AX5 rows wrap without truncation; header fixed this round.
- Xcode audit: see `accessibility.md`.

### What Works Well
- The live feed shows seeded jobs, filters them by work mode and saves into the Tracker in one batch (live run, 2026-10-24).
- Search outcome card names what was searched and what wasn't, in calm words.
- The import sheet only writes after review, and says so.

### Priority Recommendations
1. **Stack the result header at AX sizes** — no mid-word breaks.
2. **One confidence signal in import review.**
