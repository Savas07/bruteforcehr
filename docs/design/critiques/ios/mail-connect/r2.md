## Design Critique: Connect email sheet

### Overall Impression

The flow now covers every server answer calmly: not set up yet (today's live state for Google and Microsoft), wrong account, expired sign-in, blocked ports and too many attempts all say what happened and what to do, in amber or info tones, never red. The connected address comes from the server, so "Connected to …" is right even before the account document arrives.

### Usability

| Finding                                                                                                  | Severity    | Recommendation                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port_not_allowed` only surfaced after a server round trip, and changing Security left a mismatched port | 🟡 Moderate | Fixed: the form checks 993/143 (IMAP) and 465/587 (SMTP) before Connect (`MailEndpoint.isAllowed`, conformance-tested against `MAIL_ENDPOINT_PORTS`), marks the server field with one sentence naming the allowed pairs; choosing a security sets its usual port |
| `too_many_attempts` fell into the generic error                                                          | 🟡 Moderate | Fixed: "We've paused connection tests for today after several tries. Try again tomorrow."                                                                                                                                                                        |
| Reconnecting an existing mailbox showed the first-connect result (counts of a scan that didn't run)      | 🟡 Moderate | Fixed: "Reconnected {address}" + "We'll pick up new emails from here. Emails we already stored stay as they are." (`reconnect` from `mailConnectFinish`, or the reconnect route for IMAP)                                                                        |
| Address and host fields clipped long values at AX5                                                       | 🟡 Moderate | Fixed: they wrap up to three lines; Return moves on instead of inserting a line break                                                                                                                                                                            |
| Show-password toggle was a 22 pt glyph                                                                   | 🟢 Minor    | Fixed: 44 × 44 pt                                                                                                                                                                                                                                                |
| At AX5 the connected address hyphenates ("ex-ample.-com")                                                | 🟢 Minor    | Accepted: system line breaking of long words; the full address is the VoiceOver label and the account page shows it again                                                                                                                                        |

### Visual Hierarchy

- **What draws the eye first**: the provider list (Gmail / Outlook "Recommended"), then the app-password providers. On the form, the numbered help, then the fields. On the result, the green check + address.
- **Reading flow**: help → account → look back → server settings (collapsed unless needed or an error points there) → sticky Connect.
- **Emphasis**: one filled button per step, in a sticky bar that is now opaque and capped at AX1 so it never covers the form at AX5.

### Consistency

| Element                        | Issue                                                                            | Recommendation                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Sticky bars                    | Glass bar let content show through behind "Choose another provider"              | Fixed: opaque `Surface.base` bar, shared `sheet.bar` identifier as the email sheet |
| Headers / footers / trust line | System grey nearly failed contrast                                               | Fixed: `Fg.secondary` (as Settings and Mail review)                                |
| Error copy                     | Each reason maps to one message in `MailConnectStrings.message(for:)` (EN/TR/DE) | Kept                                                                               |

### Accessibility

See [accessibility.md](accessibility.md): zero Critical, zero open Moderate.

### What Works Well

- Calm `provider_not_configured`: an info alert and the app-password route, no dead end.
- Trust before credentials: what we read, what we store, disconnect any time.
- Errors point at the field they're about and are announced when they appear.

### Priority Recommendations

None open. The owner configures the Google and Microsoft OAuth clients; the OAuth steps are already built and tested with the fake service.

## Resolution

All Moderate findings fixed in this round (port pre-check, too-many-attempts copy, reconnected state, wrapping fields); the hyphenation note is accepted as system behaviour.
