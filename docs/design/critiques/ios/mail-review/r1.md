# Mail review (iOS): critique round 1

Context: Mail tab, user goal "check what the app wasn't sure about and confirm or correct it in seconds"; persona: active job seeker, often stressed and short on time, switching between phone and desktop. Stage: refinement. Focus: the To review queue (rows, account health, chips, sync line) and the no-account state. Screens: `artifacts/screens/ios/iphone-17e/mail-review-populated-light.png`, `mail-review-empty-light.png`.

## Design Critique: Mail review — To review queue

### Overall Impression
The screen reads as a calm, native mail triage list: large title, chips, a clear "We weren't sure about these" section and rows that say what we'd do and why. The biggest opportunity is the top of the screen: the account scope is invisible (the title menu has no visible affordance on a large title), the sync line is clipped, and email addresses render as teal links inside the amber card and the row chip.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Switching between All accounts and one address is only reachable through `toolbarTitleMenu`, which shows no chevron on the large title. A user with two inboxes can't discover the scope or see which one is active. | 🔴 Critical | Put the scope in the sync line as a visible menu: "All accounts ▾ · Checked 6 min. ago" (same picker as the title menu, which stays for people who know it). |
| Email addresses inside localized strings (Reconnect card title, "To deniz.aksoy@example.com" chip) are auto-detected as `mailto:` links: teal, tappable, and a tap would open Mail instead of the intended action. | 🟡 Moderate | Strip link attributes for user data in our own Text (`Text(mailPlain:)`); for the shared `InlineAlert` break detection with word joiners and ask IosFoundation for a shared fix. |
| The sync line is clipped at the leading edge ("hecked 6m ago"): the header row has a negative-feeling inset of 4 pt and the text runs under the list's edge. | 🟡 Moderate | Zero the header row insets so the line aligns with the section headers. |
| "6m ago" is terse and harder to parse for TR/DE readers; the abbreviated style also differs from the "6 min" in the research copy. | 🟢 Minor | Use the `.short` relative style ("6 min. ago"). |
| Rows from today show "Today" instead of a time, so three rows look identical in recency. | 🟢 Minor | Show the time for today's email, the day otherwise. |
| The Reconnect card is tall (three lines + link button) and pushes the queue's second row below the fold on the smallest phone. | 🟢 Minor | Logged: accepted. The card is non-dismissible by design and the queue still starts above the fold; revisit if a third account is common. |
| No pull to refresh. | 🟢 Minor | Logged: the data layer (M3) owns the "poll now" call; the sync line shows freshness meanwhile. |

### Visual Hierarchy
- **What draws the eye first**: the large "Mail" title, then the selected teal "To review (3)" chip. Correct: the count is the reason to be here.
- **Reading flow**: title → sync line → chips → reconnect card → section header → rows (sender, subject, proposal in bold, reason). Each row reads top to bottom as evidence → proposal → reason, which supports a quick, informed Confirm.
- **Emphasis**: the bold proposal line ("Move Tannenbaum Software · … from Applied to Acknowledged") is the strongest text in the row, as it should be; sender is semibold but smaller. The amber card competes slightly with the queue; acceptable while an account is broken.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Links in user data | Teal addresses look like the accent action "Reconnect" next to them | Plain text for addresses (above) |
| Chips | Category chip only appears on All job mail; fine, matches research ("last chip") | Keep |
| Monogram badges | Category glyph badges match `ClassificationBadge` and Today | Keep |

### Accessibility
- **Color contrast**: body and secondary text on grouped background pass; amber title on the warning surface passes (token pair). Teal link text inside the amber card is a contrast and meaning problem → fixed above.
- **Touch targets**: chips ≥ 44 pt; rows are full-width buttons; the new scope menu gets a 44 pt minimum height.
- **Text readability**: subject wraps to 2 lines, proposal wraps fully; AX captures pending (final round).

### What Works Well
- Each row carries evidence (sender, subject), the proposal and the reason, so the swipe-to-confirm is informed, not blind.
- The tab badge shows 3 = the To review count only; the broken account adds no badge.
- The no-account state explains the value in one sentence and has one primary action; no guilt or urgency.

### Priority Recommendations
1. **Visible account scope** — put "All accounts ▾" in the sync line.
2. **Plain addresses** — no auto-links in user data.
3. **Fix the clipped sync line** — zero header insets.

## Resolution

| Finding | Severity | Resolution |
|---|---|---|
| Account scope not discoverable | 🔴 | Fixed: scope menu in the sync line (`accountPicker` shared with the title menu). |
| Auto-linked addresses | 🟡 | Fixed: `Text(mailPlain:)` strips links in Mail views; Reconnect title uses `mailUnlinked`; shared fix requested from IosFoundation. |
| Clipped sync line | 🟡 | Fixed: header row insets zeroed. |
| Terse relative time | 🟢 | Fixed: `.short` style. |
| "Today" instead of time | 🟢 | Fixed: `MailTimeText` (time today, day otherwise). |
| Tall Reconnect card | 🟢 | Rejected: non-dismissible by design (research "Account health"); queue still starts above the fold. |
| No pull to refresh | 🟢 | Logged: needs the M3 "poll now" call. |
