## Design Critique: Saved searches

### Overall Impression
r1's fixes (labelled editor fields, a filters summary that reads as a sentence, real loading and
error states) all hold. The list and editor are calm and scannable at the default size. One layout
issue at AX5 breaks words in the most important text.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| AX5: the "New: 2" badge keeps its trailing column and squeezes the name and criteria into half the width, hyphenating "Istan-bul" and "front-end" | 🟡 Moderate | At accessibility sizes put the badge under the text so the name gets the full width |
| Editor: "Run and notify me" off shows "The search stays saved. It won't run on its own or notify you." — clear | — | None |
| Error state (Pro Max) centres the PaneError in a tall empty page | 🟢 Minor | Shared component; consistent with other screens. Keep |
| Empty: "No saved searches yet" + one-line why + "New saved search" ghost row | 🟢 Minor | Good; a "from the current search" shortcut could help later. Log |

### Visual Hierarchy
- Name (headline) → criteria (secondary) → cadence (footnote) → badge (accent fill): right order.
- Editor: Search fields → Filters summary with chevron → Alerts → destructive Delete last, separated.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Delete | Swipe + Undo toast here, Delete button + Undo toast in the editor | None |
| Hidden jobs | Same row pattern and "Show in feed" wording as the feed's Undo row | None |

### Accessibility
- **Color contrast**: badge `Accent.text` on `Accent.subtle` 7.2:1; secondary lines ≥ 10:1.
- **Touch targets**: rows full width; ghost row and toggles ≥ 44 pt.
- **Text readability**: fixed this round at AX5.

### What Works Well
- The criteria line repeats the exact filter labels the feed's chips use.
- Alerts copy explains what turning them off means instead of a bare switch.

### Priority Recommendations
1. **Badge under the text at AX sizes.**
