# Settings (iOS) — critique r1

Captures: design mode `-BFHRScreen settings -BFHRSettingsPage <page>` on the populated fixtures, iPhone 17e, light and dark (`artifacts/screens/ios/iphone-17e/settings-*-populated-{light,dark}.png`, not committed). Pages: root, mail account (needs reconnecting), job sources, companies you follow, notifications (iOS permission off), AI. Research: [settings-account.md](../../../research/settings-account.md), [mail-settings-ios-m5.md](../../../research/mail-settings-ios-m5.md). Stage: refinement (first build).

## Design Critique: Settings sheet

### Overall Impression

A native inset-grouped Settings that reads like iOS Settings: tinted symbol tiles, trailing values, and plain footers. The biggest opportunities are calmer trailing values on the root and keeping the account page from offering actions that can't work.

### Usability

| Finding                                                                                                                                                                                                                    | Severity    | Recommendation                                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Job sources shows amber "Needs attention" whenever a source is rate-limited. The user can't fix a server-side source, so the row raises alarm with no action behind it (calm principle, settings-account.md "Job sources") | 🟡 Moderate | Show "N working" on the root; the page itself lists trouble with its reason                                                     |
| Mail account page offers Check now / Check past emails again while the account needs reconnecting. Both calls fail until the user signs in again                                                                           | 🟡 Moderate | Hide them while `needs_reauth`/`error`; the Reconnect card is the one action                                                    |
| Notifications page with iOS permission off: the card says notifications are off but not that the toggles still count, so changing them looks pointless (Etsy pattern rejected in research)                                 | 🟡 Moderate | Add "Your choices below are kept and apply once notifications are on. Everything still shows up in the app."                    |
| Paused companies can only be resumed by a swipe                                                                                                                                                                            | 🟢 Minor    | Swipe + context menu through `bfhrRowActions` (the shared row-action component also exposes them to VoiceOver as actions); kept |

### Visual Hierarchy

- **What draws the eye first**: the amber "Needs attention" values on Mail accounts and Job sources. Correct for Mail accounts (the iCloud inbox needs reconnecting), wrong for Job sources (see above).
- **Reading flow**: account → Connections → Preferences → Data & privacy → About → Sign out, matching settings-account.md "Root structure".
- **Emphasis**: "Needs attention" wraps to two lines next to "Mail accounts" on the 17e, which makes the row taller than its siblings and splits the phrase.

### Consistency

| Element                           | Issue                                                                                | Recommendation                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| Notifications trailing value      | "Quiet 22:30–08:00" wraps to two lines                                               | A `moon` glyph + "22:30–08:00" (VoiceOver: "Quiet 22:30–08:00")                 |
| Appearance / Data & privacy tiles | `Fg.secondary` tile is light grey in dark mode, so the white glyph nearly disappears | A fixed mid-grey tile in both themes                                            |
| Companies "not found" row         | The warning symbol sits in a wide label column, misaligned with the text             | Symbol + text in a first-baseline HStack                                        |
| Account status row                | The status line uses footnote size while the other values use body                   | Kept: it is the shared `MailAccountStatusLine` (same as the list); noted for r2 |

### Accessibility

- **Color contrast**: amber warning text and the teal accent pass on both themes in the captures (BFHRTone/BFHRColor tokens, verified by the audit); the dark grey tile fails visually (fixed).
- **Touch targets**: rows ≥ 44 pt; Done is the system bar button.
- **Text readability**: every value wraps rather than truncates; the attention value now falls back to "Check" (TR "Kontrol", DE "Prüfen") instead of wrapping, with the full phrase as the VoiceOver label.

### What Works Well

- The root reads in one screen on the smallest iPhone, with every value visible.
- Status never relies on colour: amber dot + words, symbols + reasons on job sources and companies.
- Destructive disconnect is confirmed with exact consequences and "Keep connected" as the safe choice.

### Priority Recommendations

1. **Calm the Job sources value** — show the working count; trouble lives on the page with its reason.
2. **Only offer actions that can work** — hide Check now / past emails while the account needs reconnecting.
3. **Explain that notification choices persist while iOS has them off** — one sentence in the card.

## Resolution

- Job sources root value: "N working" only (`SettingsScreen`); trouble stays on the page with its reason.
- `AttentionValue` uses `ViewThatFits`: "Needs attention", else "Check" / "Kontrol" / "Prüfen" (new key `settings.value.needsAttentionShort`); VoiceOver always hears the full phrase.
- Quiet hours value: `moon` + "22:30–08:00", accessibility label from `settings.value.quiet`.
- Neutral tiles (Appearance, Data & privacy): fixed grey `SettingsRow.neutralTile`.
- Mail account page: Check now / Check past emails / Reconnect section only while the account works; the Reconnect card covers `needs_reauth` and `error`.
- Notifications permission card: message `notifications.permission.kept` (EN/TR/DE).
- Companies: warnings as first-baseline symbol + text.
- Status line kept in footnote size (shared with the list) — r2 re-checks it.
