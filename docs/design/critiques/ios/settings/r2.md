## Design Critique: Settings sheet

### Overall Impression

The r1 issues are closed: the root is calm (one amber "Check" for the inbox that really needs the user, "3 working" for job sources), and the account page only offers actions that can work. States read correctly in both themes and both sizes. What remains is polish.

### Usability

| Finding                                                                                                                                                             | Severity    | Recommendation                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| Loading: grey value placeholders keep the layout steady and every row stays tappable (pages show their own loading)                                                 | —           | Works; kept                                                                                                             |
| Load error: one amber `InlineAlert` "We couldn't load your settings. Changes you make still save." + Try again, values hidden instead of showing stale "0 followed" | —           | Works; kept                                                                                                             |

### Visual Hierarchy

- **What draws the eye first**: the amber dot + "Check" on Mail accounts when an inbox needs reconnecting, otherwise the account card. Correct.
- **Reading flow**: Signed in as → Connections → Preferences → Data & privacy → About → Sign out, unchanged.
- **Emphasis**: at AX5 every value moves under its label (iOS Settings behaviour), nothing truncates; the 17 Pro Max shows two more rows than the 17e and nothing else changes.

### Accessibility

See [accessibility.md](accessibility.md): zero Critical, zero open Moderate.

### What Works Well

- Calm status everywhere: amber + words, never colour alone, never red.
- Each page stays one decision deep; destructive actions are confirmed with their exact consequence.
- Loading, error and offline keep the same skeleton, so nothing jumps when data arrives.
