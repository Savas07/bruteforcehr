# Today (iOS) — critique round 1

Context: Today tab, the app's first screen. User goal: see in a few seconds what needs them today and act on it in one gesture. Persona: an active job seeker, often stressed and short on time, switching between phone and desktop. Stage: refinement. Focus: hierarchy of the five sections, trust in automatic changes, calm tone, one-gesture actions.

Captures (iPhone 17e, light, default size): `artifacts/screens/ios/iphone-17e/today-populated-light.png`, `today-populated-scroll{1,2,3}-light.png` (below the fold, from `TodayAccessibilityAuditTests.testCaptureBelowTheFold`), `today-review-sheet-light.png`, `today-empty-light.png`.

## Design Critique: Today (iOS), round 1

### Overall Impression
Calm and native: large title with the date, inset-grouped sections in the fixed order, no greeting, nothing red, and the next interview leads. The biggest opportunity is To review: the three automatic changes are taller and louder than the three decisions above them, lead with the application instead of the change, hide the reason, and sit under a header that says "3" while showing six rows.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| To review mixes decisions and automatic changes with nothing between them; the header says "To review · 3" over six rows, so the count looks wrong. | 🟡 Moderate | Add a quiet "Updated automatically" caption before the automatic rows so the count clearly belongs to the decisions. |
| Automatic-change rows (shared `AutoChangeRow`) lead with "Lumenpay · Frontend Engineer, Merchant Dashboard" in bold; the news ("Moved to Offer") is the secondary line. The evidence reason (`AutoChangeItem.reason`) isn't shown, only the sender, so the trust rule (source + reason + Undo) is half met. | 🟡 Moderate | A Today row that leads with "Moved to Offer", then company · role, then the evidence sentence, the "Automatic · Mail" tag and Undo. |
| The sender address in the automatic rows renders in the accent color (Markdown autolink in the localized string), so it looks tappable and isn't. | 🟡 Moderate | Show the evidence sentence verbatim; don't interpolate addresses into Markdown-parsed text. |
| ReviewSheet opens at the medium detent: Confirm and Change… are below the fold, so the main decision needs a scroll. | 🟡 Moderate | Open at the large detent (medium stays available to glance back). Longer term the shared sheet could pin its buttons (request to IosFoundation). |
| Next up: "Kervan Teknoloji · Product Engineer (Fr…" truncates. Meaning must never truncate. | 🟡 Moderate | Let the line wrap (`fixedSize(horizontal: false, vertical: true)`). |
| New matches use a thumbs-down glyph for "Not for me", which reads as a judgement of the company. | 🟢 Minor | Use ✕ (Nike compact pattern from research). |
| No pull to refresh. | 🟢 Minor | Logged: M0 has no data source to refresh; add with the Firestore listener (M1), where a refresh is real. |

### Visual Hierarchy
- **What draws the eye first**: the large "Today" title, then the Next up card (green kind line + bold title). Correct: the interview is the most time-sensitive item.
- **Reading flow**: Next up → To review → Follow-ups → Deadlines → New matches, top to bottom, one section per concern. Within To review, the automatic rows break the flow (see Usability).
- **Emphasis**: deadline dates and interview times are neutral text, never red, as intended. The list-style `Label` icons (clock, pin) take the wide icon column, which pushes the time text far right of the glyph and makes the deadline rows look sparse.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Icon + text lines (Next up time and place, deadline time) | `Label` inside a list row uses the list's 24 pt icon column, unlike the compact meta lines elsewhere. | One inline icon + text helper with a small secondary glyph. |
| Source tag "Automatic · Mail" (shared `SourceTag`) | Wraps onto two lines inside its capsule at default size next to the relative time. | Logged as a request to IosFoundation (let the tag hug its text; `fixedSize`). |
| Section headers | Sentence case, secondary color, plain count: consistent with the system. | Keep. |

### Accessibility
- **Color contrast**: body text uses `Fg.primary/secondary`; secondary text meets AA on the grouped background (token values). The accent kind line on white is the accent text token (AA). Pass, to be confirmed by the XCUITest audit.
- **Touch targets**: avatar, Undo, Draft follow-up and the match icon buttons are ≥ 44 pt. Pass.
- **Text readability**: good at the default size; AX5 not captured this round.

### What Works Well
- No greeting, no streaks, no counters beyond "To review · 3"; "Nothing needs you yet" with one "Find jobs" action is calm and useful.
- The date subtitle under the large title answers "which day" without decoration.
- Deadlines read as plain "Tomorrow, 10:30 AM" lines with the kind ("Next step", "Assessment") and company; nothing shouts.
- New matches give the band and one reason in a line, with Save and dismiss one tap away.

### Priority Recommendations
1. **Separate and rebuild the automatic changes in To review** — caption + a row that leads with the change and shows its evidence, source tag and Undo. Trust principle.
2. **Open ReviewSheet at the large detent** — the decision should be visible without a scroll.
3. **Stop truncation and tighten icon lines** — wrap the Next up context line, use compact inline icons.

## Resolution

| Finding | Severity | Resolution |
|---|---|---|
| To review count vs. six rows | 🟡 | Fixed: "Updated automatically" caption row before the automatic changes (`AutoChangeCaption`). |
| Automatic rows hierarchy + missing reason | 🟡 | Fixed: `AutoChangeTodayRow` leads with "Moved to {status}", then company · role, the evidence sentence (or "From an email by {sender}"), `SourceTag(.automatic)`, time and Undo / "Can't undo". Request sent to IosFoundation to show `reason` in the shared `AutoChangeRow` so Mail › Updates matches. |
| Sender looks like a link | 🟡 | Fixed: the evidence sentence is verbatim text. |
| ReviewSheet buttons below the fold | 🟡 | Fixed: opens at `.large` (`presentationDetents([.medium, .large], selection:)`). Pinned buttons requested from IosFoundation. |
| Next up truncation | 🟡 | Fixed: the context line wraps. |
| Thumbs-down glyph | 🟢 | Fixed: `xmark`. |
| List-style label icon column | 🟢 | Fixed: `InlineLabel` (small secondary glyph + wrapping text). |
| SourceTag wraps in its capsule | 🟢 | Logged: shared component, request sent to IosFoundation. |
| No pull to refresh | 🟢 | Logged: lands with the Firestore data layer (M1); a refresh gesture with nothing to refresh would be fake. |
