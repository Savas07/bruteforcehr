## Design Critique: Today (iOS), round 2

### Overall Impression
At the default size the screen is in good shape in both themes: To review now separates decisions from "Updated automatically" changes, and loading / error / offline keep the real title and tab bar. The AX5 captures are the problem: the 36 pt monogram column plus row padding leaves room for one word per line, so titles hyphenate ("inter-view", "Lu-men-pay") and the date subtitle truncates.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| AX5: row text wraps to one word per line with hyphenation because the decorative monogram keeps its column. Meaning survives but scanning collapses (a row takes a full screen). | 🔴 Critical | Hide the monogram at accessibility sizes (it's decorative; the text names the company). Same request for the shared `AutoChangeRow`. |
| AX5: the date subtitle truncates ("Thursday, October…"). | 🟡 Moderate | Use the abbreviated format ("Thu, Oct 22") at accessibility sizes. |
| AX5: New matches hide Save / ✕ (icon column would squeeze the title); the actions are only in swipe, context menu and the rotor, which is hard to discover. | 🟡 Moderate | Show "Save" and "Not for me" as labelled text buttons under the row at accessibility sizes. |
| Loading / error: the avatar renders as an empty teal circle (no initials before the profile loads). It looks broken and has no visible meaning. | 🟡 Moderate | Show the `person.crop.circle` Settings button until the profile name exists. |
| AX5 error: the shared `PaneError` truncates its title, message and "Copy details". | 🟡 Moderate | Shared component: request sent to IosFoundation (wrap + scroll). |
| Error state shows "Try again" in design mode. | — | Works: `\.bfhrReload` replays the scenario. |

### Visual Hierarchy
- **What draws the eye first**: the title, then the Next up card. Same in dark mode; the accent kind line ("On-site · round 2") stays readable on the dark card.
- **Reading flow**: unchanged and correct. The offline banner sits above Next up and reads as context, not alarm (neutral, `wifi.slash`).
- **Emphasis**: the skeleton matches the real section and row shapes; nothing jumps when data arrives.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Automatic changes | Today and Mail › Updates now share `AutoChangeRow`; Today's private copy was removed. | Keep. |
| Icon + text lines | Inline glyphs are consistent across Next up and Deadlines. | Keep. |
| InlineAlert at AX | The dismiss ✕ shares the title's line, so "Connect your email" breaks word by word. | Minor; shared component, request sent. |

### Accessibility
- **Color contrast**: dark-mode secondary text and the accent kind line read clearly on the dark grouped background (token pairs); confirmed by the audit test.
- **Touch targets**: all ≥ 44 pt, including the AX text buttons.
- **Text readability**: see the AX5 findings; fixed below.

### What Works Well
- The calm offline treatment: content stays usable with "Changes save on this device and sync when you're back online."
- Dark mode needed no screen-specific work: tokens and system semantic colors carry it.
- The error copy says what happened, reassures, and offers one action.

### Priority Recommendations
1. **Drop the decorative monogram at accessibility sizes** — restores readable line lengths.
2. **Labelled match actions at AX sizes** — keep Save / Not for me discoverable.
3. **Short date and a Settings glyph before the profile loads** — no truncation, no blank circle.

## Resolution

| Finding | Severity | Resolution |
|---|---|---|
| One word per line at AX5 | 🔴 | Fixed: `RowMonogram` hides the monogram at accessibility sizes in every Today row. Shared `AutoChangeRow` / NudgeCard: request sent to IosFoundation. |

| Match actions hidden at AX5 | 🟡 | Fixed: labelled "Save" / "Not for me" buttons under the row. |
| Blank avatar while loading | 🟡 | Fixed: `person.crop.circle` Settings button until the profile name exists. |
| PaneError truncates at AX5 | 🟡 | Shared component; request sent to IosFoundation. Today keeps its copy short (title ≤ 34 characters). Tracked to r3. |
| InlineAlert ✕ shares the title line | 🟢 | Logged; request sent to IosFoundation. |
