## Design Critique: Today (iOS), round 3

### Overall Impression
The AX5 layout now reads like a native list: titles wrap at word boundaries across the full row width, the date subtitle fits ("Thu, Oct 22"), the connect-email card and the pane error read top to bottom. The default size is unchanged and tidy. One shared layout issue remains in the automatic-change rows at AX5.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| AX5: the shared `AutoChangeRow` keeps "Undo" as a trailing column, so "Moved to Offer" wraps per word and company names hyphenate ("Lumen-pay"). Undo stays reachable (button, swipe, context menu, rotor). | 🟡 Moderate | Move Undo under the text at accessibility sizes. Shared component: requested from IosFoundation. |
| Audit: the "Prep" disclosure label was flagged "Dynamic Type partially unsupported" and "Text clipped" (system `Label` inside `DisclosureGroup`). | 🟡 Moderate | Use the same inline glyph + text as the other icon lines. |
| Audit: the Next up time line was its own tiny accessibility element ("Hit area is too small"). | 🟢 Minor | Combine time and place into one element of the card. |
| Audit: ReviewSheet header date and the 3-line snippet are "Text clipped" (shared). | 🟢 Minor | Shared component, reported to IosFoundation; the snippet truncation is intentional ("Show full email"). |

### Visual Hierarchy
- **What draws the eye first**: unchanged; at AX5 the first screen is the title, date and the Next up kind and title, which is the right first read.
- **Reading flow**: section headers ("To review · 3", "Updated automatically") break the long AX list into scannable parts.
- **Emphasis**: "Undo" in the accent color is the only colored text in an automatic row; at AX5 it competes with the title because of its column (see above).

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Monograms at AX | Today and the shared rows now use the same `CompanyMonogram(hidesAtAccessibilitySizes:)`. | Keep. |
| Icon lines | "Prep" now matches the time / place / deadline lines. | Keep. |

### Accessibility
- **Color contrast**: token pairs used on this screen are 5.8:1 or higher (see accessibility.md). Audit contrast failures were measurement artefacts (see accessibility.md); the audit harness now settles scrolls and skips text under the translucent bars.
- **Touch targets**: ≥ 44 pt everywhere, including AX text buttons.
- **Text readability**: no truncation of meaning at AX5 in Today's own rows.

### What Works Well
- AX5 empty state: the connect-email card and "Nothing needs you yet" stay readable and actionable.
- Labelled Save / Not for me under matches at AX sizes.
- Error state at AX5 scrolls instead of truncating.

### Priority Recommendations
1. **Undo under the text in `AutoChangeRow` at AX sizes** — shared, requested.
2. **Prep label** — fixed.
3. **One accessibility element for the interview time and place** — fixed.
