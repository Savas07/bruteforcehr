## Design Critique: Today on live data (iOS, M3) — r5

Captures: today matrix (populated / empty / loading / error / offline × light / dark × iPhone 17e / 17 Pro Max × default / AX5) in `artifacts/screens/ios/<device>/today-*.png`; live: `artifacts/screens/ios/tracker-live/tracker-e2e-today-empty.png`, `tracker-e2e-today.png`.

### Overall Impression
Live Today is honest about what isn't connected yet: no connect-mail card that leads nowhere, and first run offers "Log an application" instead of "Find jobs" until job search ships. Reminders and follow-ups from the Tracker appear under Deadlines and Follow-ups, and answering them is saved to the application.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Design mode still shows "Connect your email" and "Find jobs" (fixtures assume M4/M5) | 🟢 Minor | Intended: live sets `mailAvailable` / `matchesAvailable` false; design keeps the full picture for critique |
| Snooze / Not needed on a follow-up used to be device-local | 🟡 Moderate | Saved on the application (F9 fields), so desktop stops asking too |
| "Done" on a reminder deadline only hid it locally | 🟡 Moderate | Clears the reminder on the application, with Undo |
| The "coming" note could read as a promise | 🟢 Minor | Copy states a condition, not a date ("…once email and job search are connected.") |

### Visual Hierarchy
- **What draws the eye first**: the first section (Next up, or the empty state). Unchanged.
- **Footer**: "Your last 4 weeks in Insights" is a quiet link under the list, no numbers, no streaks.
