## Design Critique: Tracker (final)

### Overall Impression
In light and dark, on both devices, the Pipeline reads as one calm list: phase caption, stage header with count, and rows with a single "what's next" line. Dark mode keeps the hierarchy (the teal interview line, grey closed outcomes). The one structural gap is still drag (r2): it doesn't start in the simulator.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Drag onto the stage strip doesn't start under XCUITest (three implementations tried, r2). Move to… (long press, VoiceOver action, detail pill) and the swipes cover every move. | 🟡 Moderate | Logged as an open question for the user (keep drag on iPhone, or rely on Move to… + swipe as research OQ5 proposes). Needs a device check before more work. |
| Offline at AX5 (17e): the banner takes about half the first screen before the scope tabs. | 🟢 Minor | Shared `ConnectionBannerSection`. Accepted for M0: the banner is the important fact while offline, and it scrolls away. |
| The segmented scope picker doesn't grow at AX5. | 🟢 Minor | System control; labels stay readable. Accepted. |
| The Pro Max shows 5 rows above the fold vs 3 on the 17e. | — | Fine. |

### Visual Hierarchy
- **First**: the large title, then the stage strip. **Flow**: scope → strip → phase → stage → rows. **Emphasis**: only the interview time is in the accent color. Correct in both themes.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Dark mode | Tone dots, the opaque sticky headers (`BFHRColor.background`) and the sheet's grouped background all follow the system dark colors. | — |
| Separators in rows | Next-step and interview lines are now one `Text` each. | — |

### Accessibility
See `accessibility.md`: tokens 4.6–18:1, ≥ 44 pt targets, AX5 rows and detail without hyphenated words, every move reachable without drag.

### What Works Well
- Calm closed outcomes: grey "Not selected", and the toast "Your notes stay here."
- The trust chain on automatic moves: envelope badge on the row → "Last change came from an email" in the header → timeline row with reason, View source and Undo.
- Real chrome in loading, error and offline states.
