## Design Critique: Tracker › Calendar (iOS, M3) — r1

Captures: `artifacts/screens/ios/tracker-audit/tracker-board-calendar{,-ax}.png`, `-calendar-past`, `-calendar-empty`; `artifacts/screens/ios/tracker-live/tracker-e2e-calendar.png` (live data); tracker-board matrix (populated / empty / loading / error / offline × light / dark × iPhone 17e / 17 Pro Max × default / AX5) in `artifacts/screens/ios/<device>/`.

### Overall Impression
A calm, readable agenda: day headers, one row per thing with its kind in words, and the time right-aligned. What it does best is put overdue reminders and due follow-ups on today instead of hiding them in Past. The biggest risk was discoverability: the title menu isn't visible under a large title.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| Pipeline ↔ Calendar was only in the title menu, which has no visible affordance under a large title | 🟡 Moderate | Add a toolbar button that switches to the other view ("Show Calendar" / "Show Pipeline") |
| A suggested follow-up reads like a task ("No reply from Quill Docs yet. Send a short follow-up?") but its row has no primary action; tapping opens the application, where the card offers "Remind me to follow up" | 🟢 Minor | Keep it: the row's VoiceOver hint says it opens the application, and suggestions must never act automatically |
| Interview rows offer Add to Calendar (.ics) on the leading swipe and in the context menu only | 🟢 Minor | Fine for v1; the detail's interview row has the same action |
| Past is limited to 90 days | 🟢 Minor | Matches research (Luma); stated in the empty copy |

### Visual Hierarchy
- **What draws the eye first**: the day header, then the row title. Correct: the date is the organising axis.
- **Reading flow**: kind caption ("Reminder", "On-site · round 2") → title → company · role → time. At AX5 the time moves under the text, so nothing gets squeezed.
- **Emphasis**: "Overdue" uses the amber warning tone with a word, never red and never colour alone.

### Consistency
| Element | Issue | Recommendation |
|---------|-------|----------------|
| Day headers | Reuse the timeline's `TimelineDayHeader` ("Today", "Tomorrow", "Fri, Oct 30") | — |
| Scope control | Same segmented style as the Pipeline's Active / Closed / All | — |

### Accessibility
- **Color contrast**: passes (the audit runs on every page at the default size and AX5).
- **Touch targets**: rows ≥ 44 pt; swipe actions also available as VoiceOver custom actions.
- **Text readability**: every text wraps at AX5 (`tracker-board-calendar-ax.png`).

### What Works Well
- Overdue and due items surface on today, so nothing pending hides in Past.
- Icons plus words for each kind (person.2, bell, envelope, hourglass), never colour alone.

### Priority Recommendations
1. **Visible view switch** — done (toolbar button `tracker.switchView`).

## Resolution
- Toolbar "Show Calendar" / "Show Pipeline" added (`TrackerBoardScreen`); the title menu stays.
- `TrackerBoardAccessibilityAuditTests.testCalendarUpcoming/Past/Empty` pass at the default size and AX5.
- Open: 0 Critical, 0 Moderate.
