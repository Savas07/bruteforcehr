## Design Critique: Sign-in link landing

### Overall Impression

Ready. "BruteForceHR herunterladen" stays whole; normal German compounds still hyphenate in body text.

### Usability

| Finding                                                                                                                                                                                                                                       | Severity | Recommendation |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | -------------- |
| On Safari without the app, the automatic hand-off shows Safari's own "address is invalid" alert before the page. The page copy ("Didn't open? Make sure the app is installed") covers it; a page can't detect whether a custom scheme opened. | 🟢 Minor | Logged.        |

### Visual Hierarchy

- Primary button first, then title and hint; fallback block below a divider. Same at 375 and 1440, light and dark.

### Consistency

| Element                   | Issue              | Recommendation |
| ------------------------- | ------------------ | -------------- |
| Tokens, wordmark, buttons | Match the website. | —              |

### Accessibility (WCAG 2.1 AA)

| Check                                                                                                       | Result                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| axe-core 4 (wcag2a, wcag2aa, wcag21a, wcag21aa, best-practice), EN/DE hand-off and incomplete, light + dark | 0 violations                                                                                                                            |
| 1.3.1 Structure                                                                                             | `header` (banner), `main`, one `h1` per visible state, `section` labelled by its heading; the hidden state is `hidden` (not announced). |
| 1.4.3 Contrast                                                                                              | Site tokens; secondary text and links pass in both themes (axe).                                                                        |
| 1.4.10 Reflow                                                                                               | Single column; no horizontal scrolling at 320 px.                                                                                       |
| 2.1.1 Keyboard / 2.4.7 Focus                                                                                | All actions are links; site focus ring.                                                                                                 |
| 3.1.1 / 3.1.2 Language                                                                                      | `<html lang>` is switched with the copy (en/tr/de).                                                                                     |
| 2.5.5 Target size (AAA, informative)                                                                        | Primary button 52 px high.                                                                                                              |
| No JavaScript                                                                                               | Shows "This link isn't complete" plus a `noscript` explanation and the help link.                                                       |

### What Works Well

- The page never navigates to a URL taken from its query (no open redirect): it only wraps its own URL into the app scheme, and only for `mode=signIn` links with `oobCode` and `apiKey`.
- `Referrer-Policy: no-referrer`, `noindex`, no third-party requests: the one-time code in the URL is not leaked to other origins.

1. No Critical or Moderate findings.
