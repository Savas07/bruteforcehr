## Design Critique: Download (`/download/`)

### Overall Impression

Ready. A Mac visitor sees "Download for Mac · Apple silicon and Intel · 14.6 MB · Read this before you open it", and the link lands on the four first-launch steps inside the macOS row. A Windows visitor gets the Windows installer and the SmartScreen note. Today's real build says "No release yet" in the desktop card and still explains the iPhone beta.

### Usability

| Finding                                                                                                | Severity | Recommendation                                                                                                               |
| ------------------------------------------------------------------------------------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| At 1440 the iPhone card is shorter than the desktop card, leaving space under it.                      | 🟢 Minor | Accept: `items-start` keeps both cards at their content height; stretching would add an empty box.                           |
| When the signing certificates arrive, the first-launch notes and the Support FAQ items must disappear. | —        | They are driven by `MAC_BUILD_NOTARIZED` / `WINDOWS_BUILD_SIGNED` in `site.ts`, to flip in the change that adds the secrets. |
| Carried Minors from r1 (Download pill current-page cue).                                               | 🟢 Minor | Logged in r1.                                                                                                                |

### Visual Hierarchy

- **What draws the eye first:** the page title, then the one filled button. Correct.
- **Reading flow:** checksum, Copy and first-launch note follow the row they belong to; the "Check your download" section explains what to do with the value.

### Consistency

| Element      | Issue                                                                                      | Recommendation |
| ------------ | ------------------------------------------------------------------------------------------ | -------------- |
| Empty states | Download and Changelog now share the same message and action.                              | —              |
| Terms        | "Version 0.1.1", "Released 30 October 2026" (`en-GB` long date, UTC), sizes in decimal MB. | —              |

### Accessibility

- **Keyboard:** skip link → logo → header links → What's new → Download for Mac → Read this before you open it → Download for macOS → Copy SHA-256 of …dmg → Apple's guide → Download for Windows → Copy SHA-256 of …exe → TestFlight → All checksums → Older versions → footer. 2 px outline on every stop.
- **Screen reader:** row buttons are "Download for macOS" / "Download for Windows" (visible "Download" + hidden suffix); Copy buttons are "Copy SHA-256 of <file>"; each section is labelled by its heading.
- **Reflow:** no horizontal scrolling at 320 px or 640 px.

### What Works Well

- No file is offered without a checksum; nothing is offered before a release exists.
- Lighthouse 100 in all four categories on mobile and desktop.
