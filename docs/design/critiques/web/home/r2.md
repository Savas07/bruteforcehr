## Design Critique: Home (`/`)

### Overall Impression

Ready. On a Mac the hero now reads "Download for Mac · Version 0.1.1 · Apple silicon and Intel · 14.6 MB" with "How to open it the first time" right under it; today's real build shows "See download options" and says plainly that no release exists yet. The what's-new list scans cleanly at every width, and the footer no longer wraps.

### Visual Hierarchy

- **What draws the eye first:** heading, then the filled download pill. Correct in both schemes.
- **Reading flow:** the phone now sits directly under its "iPhone" label like the desktop tiles, so the bento reads as three equal devices.
- **Emphasis:** dark mode uses the dark checkpoint captures through `prefers-color-scheme` sources; no light screenshot flashes on a dark page.

### Accessibility

- **Color contrast:** unchanged from r1, pass (lowest text pair: `info.text` on `info.subtle` 4.64:1 light for the Beta badge).
- **Touch targets:** all standalone links and buttons ≥ 44 px (Playwright check at 375: none smaller).
- **Keyboard:** skip link → logo → Download → Changelog → Support → See what's new → Download for Mac → first-launch link → other platforms → Privacy Policy → what's-new rows → closing CTA → footer; 2 px `line.focus` outline on every stop.

### What Works Well

- Lighthouse 100 in all four categories on mobile and desktop.
